# 案例-人物走动碰撞第一视角（FPS + 推翻立方体）

与《案例-人物走动碰撞》共用同一套物理层（`model.js` 完全一致），只是把相机换成**人的眼睛**。

## 操作

- `W/A/S/D`：相对视线方向移动
- `Shift`：跑步
- **按住鼠标左键左右拖：转视角**（直接转人物本体 yaw，第一人称"看到的 = 朝向"）

## 第一人称的两个关键差异

1. **相机无阻尼**：`camera.position = 眼睛位置` 直接赋值。第三人称加阻尼是为了柔；
   第一人称加阻尼会"漂"，人动镜头慢半拍会晕
2. **看不见自己但有影子**：眼睛位置沿视线方向前探 0.3m（头模落在相机后面不挡视野），
   士兵模型保持可见 → 走路动画照常播、地面上的投影还在

HUD 中间有十字准星（纯 CSS）。

## 运行

Live Server 打开 `案例源码/index.html`。
