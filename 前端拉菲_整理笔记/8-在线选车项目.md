# 8-在线选车项目（视频 01 ~ 16）

> 项目实战：浏览器里在线选车——换车漆颜色、切换贴膜（高光/磨砂）、切换背景（展厅/户外）、切换视角（主驾驶/副驾驶/车外）、点击车门热点开关剪刀门、实时计算总价。
> 核心技术：GLTF 模型交互 + **面向对象（Car/MyLight/Sky/MySprite 等类）** + **单例模式（ClickHandler/EventBus）** + **订阅发布模式（事件总线跨模块通信）** + GSAP 补间动画。

## 01 · 项目介绍

## 03 · 汽车模型加载 —— loadManager 函数

- GLTFLoader 的 `load()` 是**异步**的，结果不能用 return 传出，要用**回调函数**。
- 封装思路：工具人函数只负责"收路径 → 返回模型对象"，后续逻辑让外边干。
- `load(path, onLoad, onProgress, onError)` 四个回调：成功 / 进度 / 错误。

`src/model/loadManager.js`（经抽帧核对）：

```js
/**
 * 专门加载模型文件的
 * @param {*} path 模型文件路径
 * @param {*} successFn 接收模型对象的成功函数
 */
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
export function loadManager(path, successFn) {
  const gltfLoader = new GLTFLoader()
  gltfLoader.load(path, gltf => successFn(gltf.scene), process => {
    console.log(process) // 加载进度
  }, error => {
    throw new Error(error) // 抛出错误对象(如 404 模型文件不存在)
  })
}
```

入口中调用（`@` 代表 src）：

```js
import { loadManager } from '@/model/loadManager'

loadManager('glb/car.glb', carModel => {
  console.log(carModel) // 组对象, 里面嵌套 100+ 小物体
})
```

## 04 · Car 类的定义和使用

- 类文件约定：**文件名和类名大写开头**（Car.js），与普通工具文件区分。
- Car 类 4 个属性：`model`（模型对象）、`scene`、`camera`、`controls`（后续切视角要用）——全部由外边 new 时传入。
- 注意执行顺序：`loadManager` 的回调是异步后执行的，等它触发时 `controls` 早已赋值，放心传。

`src/model/Car.js` 初始版：

```js
// 汽车类
export class Car {
  constructor(model, scene, camera, controls) {
    this.model = model
    this.scene = scene
    this.camera = camera
    this.controls = controls

    this.init() // new 的时候直接初始化
  }
  // 初始化汽车
  init() {
    this.scene.add(this.model)
  }
}
```

入口：

```js
import { Car } from '@/model/Car'

loadManager('glb/car.glb', carModel => {

```

## 05 · 灯光添加 —— MyLight 类

- **为什么选平行光不用环境光**：环境光只是均匀照亮所有物体，**不能产生光斑**；平行光有方向能产生光斑。不用点光源/聚光灯是因为它们参考距离（越远越暗/锥形范围），平行光更适合均匀照亮整车。
- 4 个方向（十字交叉）各一盏平行光，强度 0.5（弱一点更像真车，不刺眼）。
- **数据影响视图**：4 盏灯只有位置不同 → 把不同的值（坐标）做成数组数据，循环批量生成，而不是复制 4 遍代码。

`src/effect/MyLight.js`（经抽帧核对）：

```js
// 灯光类
import * as THREE from 'three'
export class MyLight {
  constructor(scene) {
    this.scene = scene

    // 平行光的坐标位置
    this.dirPosList = [
      [0, 5, 10],    // Z 轴正方向
      [-10, 5, 0],   // X 轴负方向
      [0, 5, -10],   // Z 轴负方向
      [10, 5, 0]     // X 轴正方向
    ]

    this.createCarDL()
  }
  // 创建照亮汽车的平行光
  createCarDL() {
    this.dirPosList.forEach(posArr => {
      const directionalLight = new THREE.DirectionalLight('#ffffff', 0.5)
      directionalLight.position.set(...posArr) // 解构展开 XYZ
      this.scene.add(directionalLight)
    })
  }
}
```

入口：`new MyLight(scene)`（加载完汽车模型之后）。

## 06 · 汽车皮肤修改（车身换物理材质）

- 目标：给车表面贴一层"薄薄的膜"→ 只有 **MeshPhysicalMaterial**（清漆 clearcoat）支持。
- 核心套路：**数据结构驱动**——
  1. 先在 three.js 官网在线编辑器（threejs.org/editor）里加载模型，点击部位 + 勾掉 visible，找到每个小物体的名字；
  2. 在 Car 类里定义 `carModel` 数据结构（name + model 占位）；
  3. init 里用 `getObjectByName` 按名字找到小物体**回填**进数据结构；
  4. 之后要改什么，遍历数据结构拿 `model` 改即可。

`Car.js` 新增（经抽帧核对）：

```js
// 车小模型对象
this.carModel = {
  'body': {
    'main': { // 车身
      name: 'Object_103',
      model: {} // 小物体对象
    },
    'roof': { // 车顶
      name: 'Object_110',
      model: {}
    },
    'leftDoor': { // 左车门
      name: 'Object_64',
      model: {}
    },
    'rightDoor': { // 右车门
      name: 'Object_77',
      model: {}
    }
  }
}

this.init()
this.modifyCarBody()
```

```js
// 初始化汽车
init() {
  this.scene.add(this.model)

  // 通过数据结构名字 => 小物体对象保存在数据结构中
  Object.values(this.carModel.body).forEach(obj => {
    // 通过名字找到小物体
    obj.model = this.model.getObjectByName(obj.name)
  })
}

// 修改车身
modifyCarBody() {
  const bodyMaterial = new THREE.MeshPhysicalMaterial({
    color: 0xff9900,       // 土豪金
    roughness: 0.5,        // 半粗糙
    metalness: 1,          // 金属度
    clearcoat: 1,          // 清漆(薄膜)
    clearcoatRoughness: 0  // 清漆不粗糙
  })
  Object.values(this.carModel.body).forEach(obj => {
    obj.model.material = bodyMaterial // 覆盖默认 Standard 材质
  })
}
```

## 07 · 添加背景 —— Sky 类

- 用**大球体包裹整个场景**（半径 10，DoubleSide 双面渲染，里面看就是天空）+ **圆形地面**（CircleGeometry）模拟展厅。
- `nowMesh` 数组：保存当前背景的两个物体对象，为后续切换时移除做准备（经验不足时想不到可以先不加，用时再补）。

`src/effect/Sky.js`（经抽帧核对）：

```js
// 天空和地面管理类
import * as THREE from 'three'
export class Sky {
  constructor(scene) {
    this.scene = scene
    this.nowMesh = [] // 当前背景的物体对象列表

    this.init()
  }
  // 初始化天空
  init() {
    // 默认-先创建室内展厅的背景环境
    this.createInDoor()
  }
  // 室内
  createInDoor() {
    // 球体
    const sphereGeo = new THREE.SphereGeometry(10, 32, 16)
    const material = new THREE.MeshBasicMaterial({ color: 0x42454c, side: THREE.DoubleSide })
    const sphere = new THREE.Mesh(sphereGeo, material)
    this.scene.add(sphere)
    this.nowMesh.push(sphere)

    // 地面(圆形, 要接收光斑阴影所以用非基础材质)
    const circleGeo = new THREE.CircleGeometry(10, 32)
    const circleMaterial = new THREE.MeshStandardMaterial({ color: 0x42454c, side: THREE.DoubleSide })
    const circle = new THREE.Mesh(circleGeo, circleMaterial)
    circle.rotation.set(-Math.PI / 2, 0, 0) // 默认垂直于X轴平面, 绕X轴反向旋转90°放平
    this.scene.add(circle)
    this.nowMesh.push(circle)
  }
}
```

> 注意：数组加元素用 `push`（JS 数组方法），场景加物体用 `add`（three.js），别混。相同颜色下地面用了 Standard 会算光照，所以看起来比球体浅。

## 08 · 车门热点标记 —— MySprite 类

- 需求：车门上小圆圈热点，**始终面向摄像机 + 能被模型遮挡** → 选**精灵物体 Sprite**（CSS2D 不被遮挡，CSS3D 不面向摄像机，都不符合）。
- 热点要**跟着车门一起动** → 精灵要 `add` 到车门物体上（作为子物体），而不是加到 scene。
- 热点坐标是**相对车门物体自身坐标系原点**的偏移，不是世界坐标系。
- **MySprite 的 constructor 显式 `return sprite`**：类默认 return this（空白对象），写了 return 就返回你 return 的值——所以这个类是"数据对象 → 精灵物体"的转换器。
- carModel 数据结构给左/右车门各加 `mark` 数组（一个车门可能有多种标记，所以是数组）。

`src/model/MySprite.js`（经抽帧核对）：

```js
// 专门产生精灵物体类
import * as THREE from 'three'
export class MySprite {
  constructor({ name, url, position, scale }) {
    const texture = (new THREE.TextureLoader()).load(url)
    const spriteMaterial = new THREE.SpriteMaterial({ map: texture })
    const sprite = new THREE.Sprite(spriteMaterial)
    sprite.position.set(...position)
    sprite.scale.set(...scale)
    sprite.name = name

    // 直接返回精灵物体对象, 而非 new 创建的空白对象
    return sprite
  }
}
```

`Car.js` 数据结构新增（经抽帧核对）：

```js

    }
  ]
},

  mark: [

```

```js
// 创建车门上精灵物体
createDoorSprite() {
  // 自定义合成数组: 只有创建精灵物体的对象在这个数组当中
  const markList = [this.carModel.body.leftDoor, this.carModel.body.rightDoor]
  // 遍历创建精灵物体
  markList.forEach(obj => {
    // 给车门所有热点标记遍历一个个生成附加的物体
    obj.mark.forEach(smallObj => {
      if (smallObj.name === 'sprite') {
        // 为数据对象生成精灵物体, 并添加到小物体模型上
        const sprite = new MySprite(smallObj)
        obj.model.add(sprite)
      }
    })
  })
}
```

## 09 · 车门开关效果（上）—— ClickHandler 数据收集

- 3D 物体鼠标交互靠 **Raycaster 光线投射**，但项目里不能到处散写 → 封装**单击处理程序类 ClickHandler**。
- **性能优化**：车模型有 100+ 小物体，不能全量 `scene.children` 挨个对比 → 只把要交互的精灵收集进 `list`，`intersectObjects(this.list)` 只跟它们比。
- **数据结构用 ES6 Map 不用普通对象**：普通对象的 key 只能是字符串，Map 的 **key 可以是任意类型（如 three.js 物体对象）**，形成"物体 → 点击回调函数"的一对一映射。
- **单例模式**：window click 事件不能绑多次；模块代码只会执行一次（import 10 次也走一遍），用 `static getInstance()` 保证全局唯一实例。注意：单例只保证实例唯一，`init` 也只能调一遍（不然事件绑多次）。

`src/utils/ClickHandler.js`（经抽帧核对）：

```js
// 整个 three.js 项目-单击事件管理类
import * as THREE from 'three'
export class ClickHandler {
  // 单例模式（静态/类方法）: 这个类被调用 n 次也只会产生同一个实例对象
  // 类方法只能由类调用, 例如: ClickHandler.getInstance()
  static getInstance() {
    if (!this.instance) {
      // 只有运行时: 第一次才会进入
      this.instance = new ClickHandler() // 实例对象
    }
    return this.instance
  }

  init(camera) {
    this.camera = camera
    this.list = [] // 光线投射交互计算的物体
    this.map = new Map() // key 可以是 three.js 物体（与点击要执行的回调函数产生一对一关系）
    // TODO: window.click 光线投射（下集补）
  }

  // 传入要点击物体和函数体
  addMesh(mesh, fn) {
    this.list.push(mesh)
    this.map.set(mesh, fn) // Map 必须用 set 赋值, 不能用中括号
  }
}
```

注册链路：

```js
// entry/index.js: 把 camera 命名导出
export { camera }  // (让外边能拿到)

// main.js: 初始化(只调一次)
import { ClickHandler } from '@/utils/ClickHandler'
ClickHandler.getInstance().init(camera)

// Car.js createDoorSprite 里: 注册精灵和回调
import { ClickHandler } from '@/utils/ClickHandler'
ClickHandler.getInstance().addMesh(sprite, () => {
  console.log('将来点击时触发这里代码')
})
```

## 10 · 车门开关效果（下）—— 光线投射 + 开关门功能完成

ClickHandler 的 init 补全（经抽帧核对）：

```js
init(camera) {
  this.camera = camera
  this.list = []
  this.map = new Map()

  // 光线投射
  const rayCaster = new THREE.Raycaster()
  const pointer = new THREE.Vector2()
  const app = document.querySelector('.app') // 注意: 画布是 .app 不是 window
  window.addEventListener('click', e => {
    // 屏幕坐标 => WebGL 设备坐标(NDC), 除以画布 app 的宽高
    pointer.x = (e.clientX / app.clientWidth) * 2 - 1
    pointer.y = -(e.clientY / app.clientHeight) * 2 + 1

    rayCaster.setFromCamera(pointer, this.camera)
    const list = rayCaster.intersectObjects(this.list) // 只和收集的物体比

    // 通过交互物体本身, 去 map 中找到对应要执行的回调函数调用
    // obj 是射线收集到的数据对象, obj.object 才是 three.js 物体对象
    list.forEach(obj => {
      const fn = this.map.get(obj.object)
      fn && fn(obj.object) // 回调并回传当前触发的 three.js 物体对象
    })
  })
}
```

Car.js 车门回调（经抽帧核对）：

```js
ClickHandler.getInstance().addMesh(sprite, (clickThreeObj) => {
  // clickThreeObj: 精灵物体
  // clickThreeObj.parent: Object_77 车门物体 (坐标轴原点在世界坐标系中心, 旋转车门有问题)
  // clickThreeObj.parent.parent.parent (才是整个车门的最大物体对象, 坐标系在车门框点固定住-旋转)
  const targetDoor = clickThreeObj.parent.parent.parent
  if (!targetDoor.userData.isOpen) {
    // 没开门 => 开门
    this.setDoorAnimation(targetDoor, { x: Math.PI / 3 })
    targetDoor.userData.isOpen = true
  } else {
    // 已开门 => 关门
    this.setDoorAnimation(targetDoor, { x: 0 })
    targetDoor.userData.isOpen = false
  }
})
```

```js
// 车门动画
setDoorAnimation(mesh, obj) {
  gsap.to(mesh.rotation, {
    x: obj.x,
    duration: 1,
    ease: 'power1.in'
  })
}
```

**关键坑（坐标系原点）**：
- 精灵的 `parent` 是 Object_77 车门 mesh，但它的坐标轴原点**在世界坐标系中心**，直接旋转会绕大圈飞出去。
- 在 three.js 在线编辑器里逐层点 parent 观察坐标系，发现要 **`parent.parent.parent`** 才是"原点钉在车门框上"的最大车门对象，旋转它才是剪刀门效果。
- three.js 物体的 `parent` 就像 DOM 的父标签，可以逐级向上找。
- **开关状态记录**：用物体的可扩展自定义属性 `userData`（每个 three.js 物体都有），自己加 `isOpen` 字段。undefined 当 false 用，`!` 取反判断。
- 直接 `rotation.set` 太生硬 → 换 gsap 补间动画（传 `{x}` 对象，只对 x 属性做动画）。

## 11 · 事件总线 EventBus（订阅发布模式）

- **问题**：menu.js（DOM 事件）要调用 Car.js 里的改色方法，直接 import 会造成两个文件**强耦合**（car 带到别的项目没意义）。
- **解耦方案**：集中式事件处理机制——事件总线（订阅发布模式的一种实现）。
  - **订阅**：`on(自定义事件名, 函数体)` → 存进 `eventObj` 对象：key = 事件名，value = 回调函数**数组**（同名事件可订阅多次）。
  - **发布**：`emit(事件名, ...参数)` → 用事件名找到数组，遍历逐个回调并把参数传回去。
- 数据结构：普通对象即可（key 是事件名字符串）；emit 用 **ES6 剩余参数 `...arg`** 接收多个实参，调用时再 `fn(...arg)` 展开按顺序传递。
- 同样用**单例模式**保证全局唯一事件中心。

`src/utils/EventBus.js`（经抽帧核对）：

```js
// 集中式-事件总线类(订阅与发布的自定义事件)
export class EventBus {
  static getInstance() {
    if (!this.instance) {
      this.instance = new EventBus()
    }
    return this.instance
  }

  constructor() {
    this.eventObj = {} // key: 事件名, value: 装入回调函数的数组
  }

  // 订阅事件
  on(eventName, fn) {
    if (!this.eventObj[eventName]) {
      // 如果这个事件名字没有注册过, 那就先声明此属性（事件名）, 赋予一个装入回调函数的数组
      this.eventObj[eventName] = []
    }
    this.eventObj[eventName].push(fn)
  }

  // 触发事件并传参
  emit(eventName, ...arg) {
    // arg 此变量是一个数组（值按实参传入先后顺序排列）
    this.eventObj[eventName].forEach(fn => {
      fn(...arg) // 展开参数数组, 按顺序一个个传递给回调函数
    })
  }
}
```

语法测试（main.js）：

```js

  console.log(oldPrice, newPrice) // 100 200
})
EventBus.getInstance().emit('changePrice', 100, 200)
```

```js
EventBus.getInstance().on('changeCarCoat', coatName => {
  if (coatName === '高光') {
    Object.values(this.carModel.body).forEach(obj => {
      obj.model.material.roughness = 0.5  // 粗糙度(完全 0 漫反射太假)

      obj.model.material.metalness = 0.5  // 为 0 太假, 一半保留透底反光的质感
      obj.model.material.clearcoat = 0    // 磨砂不需要薄膜
    })
  }
  // 同步 info.film(写在 on 的回调函数范围内, 才能拿到形参)
  this.info.film.forEach(obj => {
    obj.isSelected = false
    if (obj.name === coatName) obj.isSelected = true
  })
})
```

## 15 · 场景切换（展厅 / 户外）

- 切场景 = 换**球体和地面的贴图/材质**，由 Sky 类管理；**不用保存到服务器**（背景只是给用户看的，后台只需要颜色和贴膜）。
- **必须先 clear 再创建**：否则场景里物体越叠越多。
- **防重复点击**：`nowSkyName` 记录当前场景名，同名直接 `return` 拦住；切换后**别忘了同步更新 nowSkyName**（否则切回"展厅"被拦住回不去——视频里实际踩了这个 bug）。
- clear 流程：几何体 dispose → 材质 dispose → 材质上的纹理贴图也要 dispose → `parent.remove(obj)` 移出场景 → 清空数组 `splice(0, length)`。
- 户外贴图：球体贴 `image/desert.jpg`（720° 全景图）+ `colorSpace = THREE.SRGBColorSpace` 修正发浅；地面贴 `image/sand.jpg`，**map 和 color 可以混算**，叠加 `0xa0825a` 让土地颜色深一点。
- 球体贴全景图会有弧度穿帮感 → 把球体半径和地面都放大，看起来就像在水平线上；鼠标滚轮拉太远也会穿帮，可自行限制 OrbitControls 距离。

Sky.js 新增（经抽帧核对）：

```js
constructor(scene) {
  this.scene = scene
  this.nowMesh = []
  this.nowSkyName = '展厅' // 当前场景的名字(和标签 data-poi 的值对应)
  this.init()
}

init() {
  this.createInDoor()

  // 订阅切换场景事件
  EventBus.getInstance().on('changeSky', skyName => {
    if (skyName === this.nowSkyName) return // 防止用户反复点同一场景
    this.clear() // 清除当前物体
    if (skyName === '展厅') {
      this.createInDoor()
      this.nowSkyName = '展厅' // 别忘了同步
    } else if (skyName === '户外') {
      this.createOutDoor()
      this.nowSkyName = '户外'
    }
  })
}

// 清除球体和地面
clear() {
  this.nowMesh.forEach(obj => {
    obj.geometry.dispose()
    obj.material.dispose()
    obj.material.map && obj.material.map.dispose() // 纹理对象释放内存
    obj.parent.remove(obj)
  })
  this.nowMesh.splice(0, this.nowMesh.length) // 清空数组
}

// 户外
createOutDoor() {
  // 球体(半径放大, 减少弧度穿帮)
  const sphereGeo = new THREE.SphereGeometry(50, 32, 16)
  // 户外720°全景图片
  const sphereTexture = new THREE.TextureLoader().load('image/desert.jpg')
  sphereTexture.colorSpace = THREE.SRGBColorSpace // 颜色通道修正
  const material = new THREE.MeshBasicMaterial({ map: sphereTexture, side: THREE.DoubleSide })
  const sphere = new THREE.Mesh(sphereGeo, material)
  this.scene.add(sphere)
  this.nowMesh.push(sphere)

  // 地面
  const circleGeo = new THREE.CircleGeometry(50, 32)
  const circleTexture = new THREE.TextureLoader().load('image/sand.jpg')
  const circleMaterial = new THREE.MeshStandardMaterial({
    map: circleTexture,
    color: 0xa0825a, // color 和 map 可以混合计算, 让地面深一点
    side: THREE.DoubleSide
  })
  const circle = new THREE.Mesh(circleGeo, circleMaterial)
  circle.rotation.set(-Math.PI / 2, 0, 0)
  this.scene.add(circle)
  this.nowMesh.push(circle)
}
```

menu.js（经抽帧核对，HTML 为 `<div class="item_wrap scene_group"><div data-poi="展厅"></div><div data-poi="户外"></div></div>`）：


## 16 · 视角切换（主驾驶 / 副驾驶 / 车外）

- 核心：改**摄像机位置** + **轨道控制器 `controls.target`**（有 OrbitControls 时 `camera.lookAt` 失效）。
- 3 个视角各需一组 camera XYZ + controls target XYZ → 做成 `positionObj` 数据对象，标签上的 `data-poi` 值就是数据对象的 key。
- 直接跳太生硬 → `setCameraAnimation` 用 gsap 对 `camera.position` 和 `controls.target` 同时做补间；`...dataObj.camera` 把 {x, y, z} 三对属性**展开留在原地**，一次对 3 个属性做动画。
- 遗留问题：切到车内后玻璃/棚顶"遮光"看不清——因为那些物体材质是**单面渲染**（FrontSide），从内侧看就透了（课程到此为止，可自行把对应材质改 `side: THREE.DoubleSide` 解决）。

### 事件总线全景（本项目所有自定义事件）

| 事件名 | 订阅方（回调做什么） | 触发方（menu.js） | 传参 |

| 类/模块 | 文件 | 职责 |

| `loadManager`（函数） | model/loadManager.js | 收路径 + 成功回调，GLTFLoader 加载返回 gltf.scene |
| `Car` | model/Car.js | 车模型管理：carModel 数据结构、换材质、车门精灵、开关门、订阅 4 个事件 |

| `EventBus` | utils/EventBus.js | 单例；eventObj 订阅发布，跨模块解耦通信 |

### 本项目沉淀的通用套路

1. **数据结构驱动**：要操作多个小物体 → 先定义 `{name, model}` 数据结构 → `getObjectByName` 回填 → `Object.values().forEach` 批量操作。
2. **单例模式**：`static getInstance() { if (!this.instance) this.instance = new Xxx(); return this.instance }`——靠"模块代码只执行一次"保证唯一。
3. **订阅发布解耦**：DOM 层（menu.js）和 3D 层（Car/Sky）互不 import，全靠 EventBus 传事件名 + 参数。
4. **光线投射统一管理**：ClickHandler 集中收集可交互物体，Map 做"物体 → 回调"映射，性能 + 可维护性双赢。
5. **userData 存状态**：开关门这类状态挂在 three.js 物体的 `userData` 上，随物体走。
6. **gsap 万能补间**：`rotation` / `camera.position` / `controls.target` 都能直接 `gsap.to`，`...展开` 一次动画多个属性。
