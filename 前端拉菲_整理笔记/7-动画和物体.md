## 21 上 · GSAP 动画库

### 要点

- GSAP 是专业的补间动画库，能做 DOM 动画，也能直接操作 three.js 物体的属性（position / rotation / scale 等）。
- 使用三步（视频中的注释原文）：
  1. 下载并引入 gsap 动画库
  2. 使用 `gsap.to()` 设置动画
  3. 根据文档调整相关效果
- `gsap.to(目标对象, 配置项)`：**参数 1** 是盒子选择器 / DOM 对象 / 物体对象；**参数 2** 是动画相关配置项（对参数 1 目标对象做什么属性的变化）。
- 缓冲效果参考官方文档：https://greensock.com/docs/v3/Eases ，用内置字符串模式指定。
- `gsap.to()` 有返回值（tween 动画对象），用它可控制动画的暂停 / 恢复。

### 关键代码

```bash
npm i gsap
```

```js
import gsap from 'gsap'

let sphere // 球体对象（提升为全局，动画里要用）

function initAnimation() {
  // 2. 使用 gsap.to() 做一个补间动画
  // 参数1: 给盒选择器/DOM对象/物体对象
  // 参数2: 动画相关配置项
  const aniObj = gsap.to(sphere.position, {
    x: 5,           // 对参数 1 目标对象做什么属性的变化
    duration: 3,    // 动画持续时间
    delay: 2,       // 延迟 2 秒后在做当前动画
    repeat: -1,     // 无限次反复运动
    yoyo: true,     // 回到原点过程也有一个动画
    ease: 'expo.out', // 设置缓冲效果(参考 greensock.com/docs/v3/Eases)

    onStart() {
      console.log('开始动画')
    },
    onUpdate() {
      console.log('动画更新')
    },
    onComplete() {
      console.log('动画结束')
    }
  })

  // 补充: 控制动画暂停/恢复
  window.addEventListener('dblclick', () => {
    if (aniObj.isActive()) {
      // 当前动画运行中为 true
      aniObj.pause()
    } else {
      // 暂停->恢复
      aniObj.resume()
    }
  })
}

camera.position.set(5, 5, 5)
renderer.shadowMap.enabled = true

createLight()
createSphere()
createFloor()
initAnimation()
```

> 场景准备部分与光源章一致：`createSphere()` 绿色球体（`castShadow = true`）、`createFloor()` 白色平面（`receiveShadow = true`）、`createLight()` 环境光 + 平行光（`castShadow = true`）。

## 21 下 · 让光源跟着做动画

### 要点

- **平行光的照射目标**：`directionalLight.target = 目标物体`，灯光方向 = 灯的位置指向 target 的位置。target 改变后光线实时跟着动。
- `DirectionalLightHelper` 辅助对象要想**实时更新角度和射线**，必须在动画的 `onUpdate` 回调里手动调用 `helper.update()`。
- 因此 helper 要提升为全局变量（`let helper`），否则动画回调里访问不到。
- **调用顺序很重要**：必须先 `createSphere()` 创建出球体，再 `createLight()`（灯光的 target 依赖 sphere），最后 `initAnimation()`。
- 本集把 `repeat: -1` 和 `yoyo: true` 注释掉了，只看单程跟随效果。

### 关键代码

```js
let sphere // 球体对象
let helper // 平行光辅助对象(提升为全局变量, 动画回调里要用)

function createLight() {
  const directionalLight = new THREE.DirectionalLight('#ffffff', 1)
  directionalLight.position.set(5, 5, 5)
  directionalLight.castShadow = true
  // 关键: 让平行光始终照射球体
  directionalLight.target = sphere
  scene.add(directionalLight)

  helper = new THREE.DirectionalLightHelper(directionalLight)
  scene.add(helper)
}

function initAnimation() {
  const aniObj = gsap.to(sphere.position, {
    x: 5,
    duration: 3,
    delay: 2,
    // repeat: -1,  // 无限次反复运动
    // yoyo: true,  // 回到原点过程也有一个动画
    ease: 'expo.out',
    onUpdate() {
      console.log('动画更新')
      helper.update() // 让平行光辅助对象可以实时更新角度和射线
    }
  })
  // ... dblclick 暂停/恢复同 21 上
}

camera.position.set(5, 5, 5)
renderer.shadowMap.enabled = true

// 顺序: 先建球 -> 再建灯(target 依赖球) -> 最后做动画
createSphere()
createFloor()
createLight()
initAnimation()
```

## 22 · CSS2D 渲染器

### 要点

- `CSS2DObject`：把一个 DOM 元素转成 three.js 的 **2D 物体**，只有"位置"会跟随三维坐标，本身永远以平面方式贴在屏幕上。
- 与 CSS3D 的区别（视频中的注释原文）：
  - **CSS3D**：始终**不**面向摄像机，场景缩放时跟随着变大/变小，**会**被模型遮挡，通过 DOM 事件点击。
  - **CSS2D**：始终面向摄像机，场景缩放时**不**跟随变化，**不**被模型遮挡，通过 DOM 事件点击。
- CSS2D 里 `fontSize = '32px'` 这类 **px 像素单位仍然生效**，而不是换算成三维空间中的单位。
- 做法：把 CSS2DRenderer 封装进 `utils/init2d.js`（在 init.js 的基础上加 5 步），main.js 里 `new CSS2DObject(div)` 加入场景。

### 关键代码

`utils/init2d.js`（在 init.js 基础上新增的部分）：

```js
import { CSS2DRenderer } from 'three/addons/renderers/CSS2DRenderer.js'

export let css2dRenderer

// 1. 创建 2D 渲染器
css2dRenderer = new CSS2DRenderer()
// 2. 设置尺寸
css2dRenderer.setSize(window.innerWidth, window.innerHeight)
// 3. 设置容器样式: 盖在画布上方、不挡鼠标事件
css2dRenderer.domElement.style.position = 'fixed'
css2dRenderer.domElement.style.left = '0'
css2dRenderer.domElement.style.top = '0'
css2dRenderer.domElement.style.pointerEvents = 'none'
document.body.appendChild(css2dRenderer.domElement)

(function resizeRender() {
  window.addEventListener('resize', () => {
    renderer.setSize(window.innerWidth, window.innerHeight)
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    // 4. 适配 2D 渲染器
    css2dRenderer.setSize(window.innerWidth, window.innerHeight)
  })
})();

(function renderLoop() {
  renderer.render(scene, camera)
  // 5. 2D 渲染器渲染
  css2dRenderer.render(scene, camera)
  controls.update()
  requestAnimationFrame(renderLoop)
})();
```

`main.js`：

```js
import { CSS2DObject } from 'three/addons/renderers/CSS2DRenderer.js'

function create2d() {
  const div = document.createElement('div')
  div.innerHTML = '球体'
  div.style.color = 'red'
  div.style.fontSize = '32px'
  // 与 CSS3D 区别: 2D 物体 px 像素单位还可以生效, 而不是平移到三维空间中的单位

  const object2d = new CSS2DObject(div)
  scene.add(object2d)
}

createSphere()
createFloor()
createLight()
create2d()
```

## 23 · three.js 精灵物体（Sprite）

### 要点

- 精灵物体 = 一个**始终面向摄像机**的平面（Sprite 内部默认就是一个 1 单位的平面），用来做标签、图标、粒子等。
- 三步：① 准备纹理对象并加载图片素材 → ② 使用 `SpriteMaterial` 精灵材质 → ③ 使用 `Sprite` 创建精灵物体并加入场景。
- **精灵与 CSS2D 的区别**：精灵是场景里的真实 3D 物体，**会被模型遮挡**、随场景缩放；CSS2D 是 DOM，**不被遮挡**、不随场景缩放。按需选择。
- 精灵有 position/scale，可以放在任意三维坐标上。

### 关键代码

```js
function createSprite() {
  // 使用:
  // 1. 准备纹理对象并加载图片素材
  const texture = new THREE.TextureLoader().load('image/pkq.jpg')
  // 2. 使用 SpriteMaterial 精灵材质
  const material = new THREE.SpriteMaterial({ map: texture })
  // 3. 使用 Sprite 创建精灵物体并加入场景
  const sprite = new THREE.Sprite(material)
  sprite.position.set(3, 0.5, -3)
  scene.add(sprite)
}

createSphere()
createFloor()
createLight()
create2d()
createSprite()
```

> 图片放在 `public/image/pkq.jpg`（皮卡丘图片，Vite 静态资源根目录下的相对路径）。

## 24 · class 类的使用

### 要点

- class 是"模板"：把一类事物共有的**属性**和**方法**封装起来，之后 `new` 一下就能批量产出实例对象。
- `constructor(...)` 构造函数：`new` 的时候自动触发，参数从这里传入，属性用 `this.xxx` 绑到当前实例上。
- `new` 做的事：**创建一个空白对象 → 把这个对象赋给 this → 在 constructor 里给它绑属性 → 默认 return this**。
- 访问属性：`实例.属性`；调用方法：`实例.方法()`。

### 关键代码

```js
// 目标: class 类的使用
// 1. 定义一个 Person 类
class Person {
  // 构造函数: new 的时候自动调用
  constructor(name, age, sex) {
    // this: 指向 new 出来的实例对象
    this.name = name
    this.age = age
    this.sex = sex
  }
  // 方法直接写在类里, 不要加逗号(类不是对象)
  say() {
    console.log('我会说话')
  }
}

// 2. 实例化对象
const ldh = new Person('刘德华', 55, '男')
const xc = new Person('小船', 18, '女')

// 3. 访问属性 / 调用方法
console.log(ldh.age) // 55
console.log(xc.sex)  // '女'
ldh.say()            // 我会说话
```

## 25 · 立方体类的创建和使用（MyCube）

### 要点

- 把第一天"随机颜色/大小/位置的立方体"封装成一个类，对比以前散乱写法的差异。
- MyCube 类共 **5 个属性 + 3 个方法**：
  - 属性：`model`（保存 three.js 创建出来的立方体对象）、`scene`（要加入到哪个场景，以后可能有多个场景）、`color`、`position`、`size`
  - 方法：`init`（初始化立方体）、`randColor`（改变颜色）、`rotate`（旋转）
- **为什么 scene 要靠 new 传入而不直接用全局变量**：项目大了要分模块（分 js 文件），类被拿走后全局就没有 scene 了，必须动态传入。
- **为什么加 model 属性**：mesh 物体后续要在别的方法（randColor / rotate）里访问，`this.model = mesh` 把它挂到实例上。
- **this 指向**：实例对象调用方法时，方法里的 this 就是当前函数的调用者（即该实例对象）。创建 5 个 cube，每个对象各有自己的 init/randColor/rotate，互不影响。
- 类是语法结构不是对象，**方法之间千万不要写逗号**。
- 位置/大小用数组存 3 个值，用时 `...this.size` 展开传给 BoxGeometry / position.set。
- 想让立方体"出生"位置就随机：在 init 里 `mesh.position.set(...this.position)`，内聚到类中，外边代码更干净。

### 关键代码（经抽帧核对）

```js
import { scene } from './utils/init'
import * as THREE from 'three'

// 目标: 立方体类 MyCube 的创建与应用
// 1. 定义 MyCube 类以及属性和方法
// 2. 循环创建 5 个立方体并出现在三维空间中

// 1. 定义 MyCube 类以及属性和方法
class MyCube {
  constructor(scene) {
    this.color = new THREE.Color(`rgb(${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)})`)
    this.position = [Math.floor(Math.random() * (5 - 0 + 1) + 0), Math.floor(Math.random() * (5 - 0 + 1) + 0), Math.floor(Math.random() * (5 - 0 + 1) + 0)]
    this.size = [Math.floor(Math.random() * (3 - 1 + 1) + 1), Math.floor(Math.random() * (3 - 1 + 1) + 1), Math.floor(Math.random() * (3 - 1 + 1) + 1)]

    this.scene = scene

    this.init() // new 的时候就直接创建立方体
  }

  init() {
    // 当前 init 方法以后是实例对象来调用, this 指向当前函数的调用者
    const geometry = new THREE.BoxGeometry(...this.size)
    const material = new THREE.MeshBasicMaterial({ color: this.color })
    const mesh = new THREE.Mesh(geometry, material)
    mesh.position.set(...this.position)
    this.scene.add(mesh)
    this.model = mesh // 为了以后在别的方法里可以访问到这个 mesh 物体(颜色修改/旋转操控)
  }

  randColor() {
    this.model.material.color = new THREE.Color(`rgb(${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)})`)
  }

  rotate() {
    this.model.rotation.set(0, Math.PI / 4, 0)
  }
}

// 2. 循环创建 5 个立方体
const arr = [] // 装入我们自己 new 出来的实例对象(普通 JS 对象, 不是 three.js 物体)
for (let i = 0; i < 5; i++) {
  arr.push(new MyCube(scene))
}
console.log(arr) // 实例对象的 model 属性才指向 three.js 真正的 Mesh

// 双击: 批量修改随机颜色
window.addEventListener('dblclick', () => {
  arr.forEach(cube => {
    // 用我们自己的管理对象, 调用自己类中的方法
    cube.randColor()
  })
})
```

> 随机数公式：`Math.floor(Math.random() * (最大值 - 最小值 + 1) + 最小值)`。

## 26 · 球体类和基类的使用（MySphere / BaseModel）

### 要点

- 立方体类和球体类对比后发现**公共属性 / 公共方法** → 提取成**基类（父类）BaseModel**。
  - 基类属性：`model`、`scene`、`color`、`position`；基类方法：`randColor`。
  - `init` 不提取：虽然方法名一样，但内部代码不同（立方体用 `BoxGeometry`，球体用 `SphereGeometry`）。**提取到基类的前提：名字一致且方法内代码也一致。**
- **继承两步**：`class 子类 extends 基类` + 子类有 constructor 时**第一行必须调 `super(参数)`**。
  - `super(scene)` 触发父类构造函数并绑定公共属性和父类方法；`super` 还会把当前函数内的 **this 值传递给父类**构造函数内的 this 进行替换——所以父类里绑的属性实际绑在了子类实例对象上。
- 基类里 `this.model = null`：new 的阶段 mesh 还没创建，占位空值，在子类的 init 中后续创建和赋值。
- 基类的 this 指向**子类对象**（看你 new 的是立方体还是球体）。基类一般不直接 new，只作为公共模板。
- MySphere 自己只需要 **1 个特有属性（radius）+ 1 个方法（init）**，其余全靠继承。
- 继承的价值：想控制某个物体只要找到它对应的类，内聚性高、扩展性好（想加行为就往类里加方法）。

### 关键代码（经抽帧核对）

```js
import { scene } from './utils/init'
import * as THREE from 'three'

// 目标: 提取公共部分成基类 BaseModel, 让 MyCube / MySphere 继承
// 1. 创建 BaseModel 提取公共属性和方法
// 2. 修改 MyCube 类继承自 BaseModel 类
//    继续: 让父类往当前类实例化对象上, 绑定属性和方法
// 3. 创建 MySphere 类并实例化 5 个球体

// 1. 创建 BaseModel 提取公共属性和方法
class BaseModel {
  constructor(scene) {
    // this: 子类对象
    this.model = null // 这个值是在子类 init 中后续创建和赋值
    this.scene = scene
    this.color = new THREE.Color(`rgb(${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)})`)
    this.position = [Math.floor(Math.random() * (5 - 0 + 1) + 0), Math.floor(Math.random() * (5 - 0 + 1) + 0), Math.floor(Math.random() * (5 - 0 + 1) + 0)]
  }

  randColor() {
    // this: 子类对象
    this.model.material.color = new THREE.Color(`rgb(${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)}, ${Math.floor(Math.random() * 256)})`)
  }
}

// 2. 修改 MyCube 类继承自 BaseModel 类
class MyCube extends BaseModel {
  constructor(scene) {
    super(scene) // 必须在第一行: 触发父类构造, 绑定公共属性和方法
    // size 是立方体自己的特有属性
    this.size = [Math.floor(Math.random() * (3 - 1 + 1) + 1), Math.floor(Math.random() * (3 - 1 + 1) + 1), Math.floor(Math.random() * (3 - 1 + 1) + 1)]

    this.init()
  }

  init() {
    const geometry = new THREE.BoxGeometry(...this.size)
    const material = new THREE.MeshBasicMaterial({ color: this.color })
    const mesh = new THREE.Mesh(geometry, material)
    mesh.position.set(...this.position)
    this.scene.add(mesh) // this.scene 由 super 让父类绑到子类对象上, 不会报错
    this.model = mesh
  }

  rotate() {
    this.model.rotation.set(0, Math.PI / 4, 0)
  }
}

// 3. 创建 MySphere 类并实例化 5 个球体
class MySphere extends BaseModel {
  constructor(scene) {
    super(scene)
    this.radius = Math.floor(Math.random() * (2 - 1 + 1) + 1) // 球体特有属性: 半径 1~2

    this.init()
  }

  init() {
    const geometry = new THREE.SphereGeometry(this.radius, 32, 16)
    const material = new THREE.MeshBasicMaterial({ color: this.color }) // color 继承自基类
    this.model = new THREE.Mesh(geometry, material)
    this.model.position.set(...this.position) // position 也是父类绑定的随机值
    this.scene.add(this.model)
  }
}

// 外边代码相当于"管家": 想让谁干活 new 谁就行
const arr = []
for (let i = 0; i < 5; i++) {
  arr.push(new MyCube(scene))
  arr.push(new MySphere(scene))
}

// 双击: 遍历自己的实例对象数组, 调用基类继承来的 randColor 改颜色
window.addEventListener('dblclick', () => {
  arr.forEach(obj => obj.randColor())
})
```

> 注意：球体和立方体坐标可能重叠（有的球被包在立方体里），刷新随机位置后即可看到 5 球 + 5 立方体。

## 本章速查表

### GSAP `gsap.to(target, vars)` 常用配置

| 配置 | 作用 |
| --- | --- |
| `x / y / z` 等 | 目标属性最终值（直接写目标的属性名） |
| `duration` | 动画持续时间（秒） |
| `delay` | 延迟多少秒后开始 |
| `repeat: -1` | 无限次反复 |
| `yoyo: true` | 返程也播放动画（来回） |
| `ease: 'expo.out'` | 缓冲效果，查 greensock.com/docs/v3/Eases |
| `onStart / onUpdate / onComplete` | 开始 / 每帧更新 / 结束回调 |
| 返回值 tween | `.isActive()` / `.pause()` / `.resume()` 控制播放状态 |

### CSS3D / CSS2D / Sprite 三者对比

| 能力 | CSS3DObject | CSS2DObject | Sprite 精灵 |
| --- | --- | --- | --- |
| 面向摄像机 | 否（随场景旋转） | 始终面向 | 始终面向 |
| 场景缩放 | 跟随变大/变小 | 不跟随（px 生效） | 跟随 |
| 被模型遮挡 | 会 | **不会** | **会** |
| 渲染器 | CSS3DRenderer | CSS2DRenderer | WebGLRenderer（场景内） |
| 典型用途 | 展厅内的"墙上网页" | 标签/地名标注 | 图标、粒子 |

### class / 继承要点

- 属性写在 `constructor` 里用 `this.xxx = ...`；方法直接并列写，**方法之间不加逗号**。
- `new` 流程：创建空白对象 → 赋给 this → constructor 绑属性 → 默认 return this。
- 方法里的 this = 当前调用者（点前边的那个对象）。
- 继承 = `extends` + 子类 constructor 第一行 `super(...)`；super 会把子类的 this 传给父类构造函数。
- 提取基类的标准：属性/方法**名字一致且内部代码一致**才提取；只有名字一致（如 init）不提取。
