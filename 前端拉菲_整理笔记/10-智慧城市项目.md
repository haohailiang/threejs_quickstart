## 02 项目-模型加载

**要点：** 封装通用加载函数 `loadManager(pathList, successFn)`，支持 fbx / gltf 混合加载，**多个异步全完成后再统一回调**（面试题考点）。

**关键代码（src/model/loadManager.js）：**
```js
import { FBXLoader } from 'three/examples/jsm/loaders/FBXLoader'
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader'

export function loadManager(pathList, successFn) {
  const fbxLoader = new FBXLoader()
  const gltfLoader = new GLTFLoader()
  const modelList = []

  pathList.forEach(path => {
    // 通过路径后缀字符串判断用哪个加载器
    if (path.indexOf('fbx') !== -1) {
      fbxLoader.load(path, model => {
        modelList.push({ model, url: path })
        // 所有异步加载全部完成后才回调
        if (modelList.length === pathList.length) successFn(modelList)
      })
    } else if (path.indexOf('gltf') !== -1) {
      gltfLoader.load(path, model => {
        // 注意：GLTF 要通过 .scene 拿真正的模型对象
        modelList.push({ model: model.scene, url: path })
        if (modelList.length === pathList.length) successFn(modelList)
      })
    }
  })
}
```

**入口调用：**
```js
loadManager(['fbx/city.fbx', 'gltf/ship.glb'], modelList => {
  modelList.forEach(obj => {
    if (obj.url === 'fbx/city.fbx') { /* new City(...) */ }
    else if (obj.url === 'gltf/ship.glb') { /* new Ship(...) */ }
  })
})
```

**代码解释：** 每加载完一个模型就往 `modelList` 里 push `{model, url}`，用 `modelList.length === pathList.length` 判断"全部加载完毕"——这是前端处理**多异步并发完成**的经典写法。

## 04 项目-城市细节修改-材质颜色

**要点：** `initEffect()` 遍历城市模型，隐藏内置文字标签、排除地板与河水、按名字区分中心/外围建筑并分别赋予材质。

**关键代码（City.js）：**
```js
initEffect() {
  // 中心建筑材质
  const centerMaterial = new THREE.MeshBasicMaterial({
    color: 0xA8CDED,
    transparent: true
  })
  // 外围建筑材质
  const periphery = new THREE.MeshBasicMaterial({
    color: 0xA8CDED,
    transparent: true
  })

  this.model.traverse(model => {
    // 隐藏建模师内置的文字标签（名字为 text 的物体）
    if (model.name === 'text') {
      model.visible = false
      return   // ⚠️ 必须 return，否则代码继续往下走 else 分支，标签会重新出现（05 集 bug）
    }
    // 排除地板和河水（它们不做白膜处理）
    if (model.name !== '上海_09_floor' && model.name !== '上海_08_river') {
      // 按名字区分中心/外围：上海_02 ~ 上海_07 为外围
      if (/* 名字属于外围 */) model.material = periphery
      else model.material = centerMaterial
    }
  })
}
```

**代码解释：** FBX 模型本身是"一坨"Mesh 集合，用 `traverse` 逐个 Mesh 改写材质；`名字`是建模师在模型里命名好的小物体名，是本项目所有定位手段的基础（`getObjectByName` 也依赖它）。

## 05 项目-城市细节修改-边线设置

**要点：** 用 `EdgesGeometry + LineSegments` 给每个建筑加轮廓边线，并用 `copy()` 把原 Mesh 的 position/rotation/scale 同步给边线（**copy 接收 Vector3 对象，set 接收三个数**）。

**关键代码（src/effect/EdgesLine.js）：**
```js
import * as THREE from 'three'

export class EdgesLine {
  constructor(mesh, color) {
    // 提取几何图形的边线
    const edges = new THREE.EdgesGeometry(mesh.geometry)
    const material = new THREE.LineBasicMaterial({ color })
    const line = new THREE.LineSegments(edges, material)
    // 同步原物体的位置/旋转/缩放，否则边线会跑偏到原点
    line.position.copy(mesh.position)
    line.rotation.copy(mesh.rotation)
    line.scale.copy(mesh.scale)
    mesh.parent.add(line)  // 挂到同一父级
  }
}
```

**City.js 中的使用：**
```js
import { EdgesLine } from '@/effect/EdgesLine'

// initEffect 内对中心与外围建筑分别：
new EdgesLine(model, new THREE.Color(0x666666))
```

**踩坑实录（视频内真实 bug）：** 04 集隐藏 `text` 标签时忘了 `return`，代码继续进入 else 分支又被加了边线，导致被隐藏的文字标记重新出现 → 05 集加上 `return` 修复。

## 06 项目-城市细节修改-着色器（白膜渐变）

**要点：** 用 `material.onBeforeCompile` 在着色器编译前拦截，用 `shader.fragmentShader.replace(...)` 改写内置材质着色器，注入自定义 uniforms 实现"从地面向上渐隐"的白膜扫描效果。

**关键代码（src/shader/modifyCityMaterial.js）：**
```js
export function modifyCityMaterial(mesh, isCenter) {
  mesh.material.onBeforeCompile(shader => {
    // 计算包围盒拿到建筑高度范围
    mesh.geometry.computeBoundingBox()
    const { min, max } = mesh.geometry.boundingBox

    // 注入自定义 uniforms
    shader.uniforms.cityColor = { value: new THREE.Color(0x00FFFF) } // 中心色
    shader.uniforms.minY = { value: min.y }
    shader.uniforms.maxY = { value: max.y }
    // ... GradColor 等 4 个 uniforms

    // 改写片元着色器：声明变量 + 替换关键语句
    shader.fragmentShader = shader.fragmentShader.replace(
      '#include <common>',
      `#include <common>
       uniform vec3 cityColor;
       uniform float minY;
       uniform float maxY;
       varying vec3 vPosition;`
    )
    // 顶点着色器同理：把 position 通过 varying 传给片元
  })
}
```

**City.js 使用：** 在 initEffect 赋材质后调用 `modifyCityMaterial(model, isCenter)`。

**代码解释：** `onBeforeCompile` 是"不改源码前提下魔改内置材质"的标准手段；`varying` 负责顶点→片元传值；白膜效果 = 按片元的 Y 坐标在 min.y~max.y 之间做线性渐变。

## 10 项目-火灾标记

**要点：** 火灾标记用**精灵物体**（始终面向摄像机）；位置依赖目标建筑的**中心点 + 半高**计算，而不是手写死坐标——"标记类物体依赖目标物体决定坐标"。

**工具函数（src/utils/getBoxCenter.js）：** 基于 `THREE.Box3` 包围盒计算中心点与尺寸
```js
import * as THREE from 'three'

export function getBoxCenter(object) {
  const box = new THREE.Box3().setFromObject(object)  // 用盒子包裹目标物体
  const center = new THREE.Vector3()
  const size = new THREE.Vector3()
  box.getCenter(center)   // 中心点
  box.getSize(size)       // 宽高深
  return { center, size }
}
```

**关键代码（src/effect/Fire.js）：**
```js
import * as THREE from 'three'

export class Fire {
  constructor(scene, center, size) {
    this.scene = scene
    this.center = center   // 建筑物中心点 Vector3
    this.size = size       // 建筑物大小 Vector3
    this.init()
  }
  init() {
    const texture = new THREE.TextureLoader().load('icon/fire.png')
    texture.colorSpace = THREE.SRGBColorSpace   // 修正颜色通道（否则贴图偏浅）
    const spriteMaterial = new THREE.SpriteMaterial({ map: texture })
    const sprite = new THREE.Sprite(spriteMaterial)
    // +3 让精灵物体中心点不在建筑顶端，再往上移一些
    sprite.position.set(this.center.x, this.center.y + this.size.y / 2 + 3, this.center.z)
    sprite.scale.set(10, 10, 10)   // 默认太小，放大 10 倍
    this.scene.add(sprite)
  }
}
```

**City.js 中调度：**
```js
import { getBoxCenter } from '@/utils/getBoxCenter'
import { Fire } from '@/effect/Fire'

// buildName 就是建模师模型中的小物体名字
initFire(buildName) {
  const build = this.model.getObjectByName(buildName)
  const { center, size } = getBoxCenter(build)
  new Fire(this.scene, center, size)
}
// init() 中调用：this.initFire('01上海中心大厦')
```

**定位公式（通用套路）：** 标记 Y 坐标 = 建筑中心点 Y + 建筑高度/2 + 额外偏移；X/Z 直接用中心点。

## 11 项目-火灾影响范围标记

**要点：** 用 `SphereGeometry` 的后 4 个参数做**半球体**；关闭深度测试 `depthTest: false` 实现**透视效果**（球体与建筑重合的像素点都渲染）。

**SphereGeometry 7 个参数：** `(radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength)`
- phiStart/phiLength：水平（经线）起始/扫描角度，默认 0 ~ Math.PI*2（一整圈）
- thetaStart/thetaLength：垂直（纬线）起始/扫描角度，默认 0 ~ Math.PI
- 半球体：垂直方向只扫一半 → `thetaLength = Math.PI / 2`

**关键代码（src/effect/FireBall.js）：**
```js
import * as THREE from 'three'

export class FireBall {
  constructor(scene, center) {
    this.scene = scene
    this.center = center
    this.init()
  }
  init() {
    const geometry = new THREE.SphereGeometry(
      25, 32, 16,
      0, Math.PI * 2,   // 水平方向扫描一整圈
      0, Math.PI / 2    // 垂直方向只扫一半 → 半球体
    )
    const material = new THREE.MeshBasicMaterial({
      color: new THREE.Color('#f4790d'),
      side: THREE.DoubleSide,
      depthTest: false   // 关闭深度测试 → 透视效果，能透过球体看到建筑
    })
    const sphere = new THREE.Mesh(geometry, material)
    sphere.position.set(this.center.x, 0, this.center.z)  // Y 直接给 0，贴在地平面
    this.scene.add(sphere)
  }
}
```

**City.js 中：** 在 initFire 里创建 Fire 之后紧接着 `new FireBall(this.scene, center)`。

**代码解释：** 渲染管线光栅化最后一个阶段是"逐片元操作/合并测试"——同一像素位置既有建筑又有球体时由深度测试决定谁盖住谁；关掉后两个都渲染，形成透视。

## 13 项目-水波纹动态效果（动效管理类架构）

**要点：** 这是**项目动效架构的核心一集**——所有动效统一走"渲染循环 + 单例管理类"模式。

**为什么不直接用 setInterval？** 浏览器切到后台 setInterval 仍在跑；`requestAnimationFrame` 最小化时自动暂停调度，切回来恢复——所以全项目动效都依赖渲染循环。

**核心机制：** Water 材质内置 `uniforms.time`，不断赋新的偏移值即可让波纹流动。

**关键代码 1（CityWater.js 新增 onTick）：**
```js
// 给水波纹做动画
onTick(t) {
  // t 的值：渲染循环启动过了多少毫秒时间；除以 1000 → 过一秒才偏移一个单位
  this.model.material.uniforms['time'].value = t / 1000
}
```

**关键代码 2（src/utils/EffectManager.js 单例动效管理类）：**
```js
export class EffectManager {
  constructor() {
    this.list = []   // 保存要做动效的实例对象（注意：是我们自己类实例化的普通 JS 对象，不是 three 物体）
  }
  // 单例模式：整个项目只需要一个管理类
  static getInstance() {
    if (!this.instance) {
      this.instance = new EffectManager()
    }
    return this.instance
  }
  // 添加要做动效的实例对象
  addObj(obj) {
    this.list.push(obj)
  }
  // 遍历调度每个实例对象内置的 onTick 方法
  tickForEach(t) {
    this.list.forEach(obj => obj.onTick(t))
  }
}
```

**关键代码 3（City.js 注入水物体）：**
```js
import { EffectManager } from '@/utils/EffectManager'

// 把水波纹物体注入传入到动效管理类当中
const theWater = new CityWater(model, this.scene)
EffectManager.getInstance().addObj(theWater)
```

**关键代码 4（entry/index.js 渲染循环）：**
```js
// 渲染循环
function renderLoop(t) {
  // 这里不再调用轨道控制器 update 方法，会影响摄像机 lookAt
  renderer.render(scene, camera)
  css2Renderer.render(scene, camera)
  // 开始做动效->遍历所有要做动效的实例物体内置的 onTick 方法
  EffectManager.getInstance().tickForEach(t)
  requestAnimationFrame(renderLoop)
}
```

## 18 项目-鸟瞰模式

**要点：** 天上放一个沿椭圆路径飞行的立方体模拟"飞机"；点击"城市鸟瞰"后**摄像机 position 跟随飞行器坐标** → 鸟瞰。核心思想：画面由摄像机决定，改摄像机位置即可；用**开关属性**控制是否跟随（渲染循环每秒调度 onTick 约 60 次，开关为 true 才执行跟随代码）。

**关键代码（src/model/Fly.js，继承 BaseModel）：**
```js
init() {
  this.scene.add(this.model)
  this.pointIndex = 0
  this.isCameraMove = false   // 控制摄像机是否跟随切换位置的开关
  this.generateMovePath()
}
// 飞行器运动的路径
generateMovePath() {
  // EllipseCurve 椭圆曲线
  const AirFly_PATH = new THREE.EllipseCurve(
    0, 0,              // 椭圆中心坐标
    110, 110,          // x和y轴向上椭圆的半径
    0, -2 * Math.PI,   // 开始角度和扫描角度
    false,             // 是否按照顺时针来绘制
    0                  // 椭圆从X轴正方向逆时针的旋转角度（弧度）
  )
  let tempArr = AirFly_PATH.getPoints(this.pointSize)
  // 把坐标向 y 轴移动 120 单位（模仿在天空的效果）
  let result = []
  for (var i = 0; i < tempArr.length; i++) {
    // 椭圆曲线默认在 XOY 平面（垂直于世界坐标系），其 y 分量转过来是三维的 z
    let item = new THREE.Vector3(tempArr[i].x, 120, tempArr[i].y)
    result.push(item)
  }
  this.pointsArr = result
}
// 动效-不断切换最新的坐标点
onTick() {
  if (this.pointIndex < this.pointsArr.length - 1) {
    // 重要：如果其他东西也要跟着我的坐标来动
    if (this.isCameraMove) {
      // 更改摄像机位置
      this.camera.position.copy(this.pointsArr[this.pointIndex])
      // 让摄像机中心观察点往上偏移一点（看向城市中心）
      this.camera.lookAt(0, 10, 0)
    }
    this.model.position.copy(this.pointsArr[this.pointIndex])
    this.pointIndex += 1   // 调节速度
  } else {
    this.pointIndex = 0
  }
}
```

**入口（entry/index.js）：**

**要点：** 让摄像机"坐在船上"跟随游船移动、始终看向船头前进方向。做法同鸟瞰——改 Ship 的 onTick + 开关属性 `isMoveCamera` + menu.js 点击 + EventBus。

## 20上 项目-漫游模式-相机旋转

**要点：** 漫游模式下按住鼠标左键**水平旋转**摄像机。核心三步：① 仅在漫游模式绑鼠标事件；② `isMouseTouching` 属性记录按下/抬起状态；③ move 时用 `rotateY(偏移量*0.01)` 累加旋转。

**关键代码（src/model/Ship.js 新增）：**
```js
init() {
  // ...原有
  this.onModelAttach()   // 鼠标相关事件的绑定
}
// 绑定/移除鼠标事件
onModelAttach() {
  // 点击漫游模式 - 绑定/移除鼠标相关事件（事件名 = 按钮 id）
  EventBus.getInstance().on('mode-roaming', (isOpen) => {
    if (isOpen) {
      window.addEventListener('mousedown', this.mousedownFn)
      window.addEventListener('mousemove', this.mousemoveFn)
      window.addEventListener('mouseup', this.mouseupFn)
    } else {
      window.removeEventListener('mousedown', this.mousedownFn)
      window.removeEventListener('mousemove', this.mousemoveFn)
      window.removeEventListener('mouseup', this.mouseupFn)
    }
  })
}
// 鼠标按下
mousedownFn() {
  this.isMouseTouching = true   // 鼠标已经按下
}
// 鼠标移动（无论是否按下都会触发，所以必须配合状态判断）
mousemoveFn(e) {
  if (this.isMouseTouching) {   // 只有按下时进入此逻辑代码
    // 旋转核心思想：在原有的旋转角度基础上，新增移动的偏移量，乘以 0.01 让旋转弧度降低
    // rotateY() 在上一次旋转的角度上继续新增你传入的弧度数值（累加）
    // rotation.y = 直接赋予一个旋转的最终弧度数值（覆盖）
    this.camera.rotateY((this.prePos - e.clientX) * 0.01)
    this.prePos = e.clientX     // 把最新屏幕坐标存为"上一个坐标"
  }
}
// 鼠标抬起
mouseupFn() {
  this.isMouseTouching = false
  this.prePos = undefined       // 清空上一次记录的坐标点位置（否则下次按下会从旧位置接着转）
}
```

**onTick 配套修改（解决与 lookAt 的冲突）：**
```js
if (this.isMoveCamera) {        // 移动摄像机
  if (!this.isMouseTouching) {  // 鼠标没有被按下时，才设置摄像机的 lookAt
    this.camera.lookAt(x, y + 20, z)
  }
  this.camera.position.set(x, y + 20, z)   // 无论是否旋转，摄像机都要跟着移动
}
```

**冲突原理：** `camera.lookAt` 会锁定摄像机朝向，与手动 `rotateY` 互相覆盖 → 鼠标按下时跳过 lookAt。同理：渲染循环里**不要调** `controls.update()`，否则轨道控制器也会一直把摄像机锁回它创建时的观察点。

## 20下 项目-漫游模式-bug修复（bind 经典坑）

**Bug 现象：** 退出漫游模式后，再用轨道控制器旋转出现**抖动**。

**根因：** `addEventListener('mousedown', this.mousedownFn.bind(this))` —— `bind` 每次在原地创建**新函数体**，`removeEventListener` 传的又是另一个新函数体，**不是同一个引用 → 移除失败**，残留的 mousemove 监听继续干扰摄像机。

**修复：** 把三个方法改成**类字段箭头函数**定义（不再是原型上的方法，而是实例属性，this 天然指向实例，且 add/remove 拿到同一个函数引用）：
```js
// 鼠标按下
mousedownFn = () => {
  this.isMouseTouching = true
}
// 鼠标移动
mousemoveFn = (e) => { /* ... */ }
// 鼠标抬起
mouseupFn = () => {
  this.isMouseTouching = false
  this.prePos = undefined
}
```
箭头函数的 this 指向定义处外层（实例），同时保证了 add/remove 引用一致——一举两得。

## 21 项目-模型进度加载（LoadingManager + GSAP）

**要点：** 用 three.js 内置 `LoadingManager` 替代 02 集手写的"数量对比"判断；配合 **GSAP 补间动画**做百分比数字滚动 + 进度条动画。

**LoadingManager 四个回调：** `onStart`（开始）、`onLoad`（全部加载完成）、`onProgress(url, loadedNum, totalNum)`（**每加载完一项回调一次**，参数=已加载项URL/已加载个数/总个数）、`onError`（出错）。用法：实例化后**传进每个 loader 的构造函数**。

**关键代码（src/model/loadManager.js 改造）：**
```js
import gsap from 'gsap'
import * as THREE from 'three'

export function loadManager(pathList, suc) {
  // 基于 three.js 提供的 LoadingManager 创建管理器对象
  const manager = new THREE.LoadingManager()
  // 丢进每个加载器构造函数
  const fbxLoader = new FBXLoader(manager)
  const gltfLoader = new GLTFLoader(manager)

  let preValue = 0   // 上一次的进度值
  // 给加载器对象关联属性和回调函数
  manager.onProgress = (url, loadedNum, totalNum) => {
    // * 100 目的：为了让 0.5 进度变成 50 后续添加 % 后缀
    let progressRatio = Math.floor(loadedNum / totalNum * 100)

    gsap.fromTo('#processing-number', {
      innerText: preValue   // 暂时先传入一个数字（后面再去加 % 字符串）
    }, {
      innerText: progressRatio,
      onUpdate() {
        // 详细控制显示的内容
        // 取出当前正在做动画的目标对象的属性值（进度数字）
        const num = gsap.getProperty(this.targets()[0], 'innerText')
        this.targets()[0].innerText = num + '%'
      }
    })
    // 对进度条再来做一个动画（scaleX 范围 0~1，所以 0~100 的进度要除以 100）
    gsap.fromTo('#loading-bar', { scaleX: preValue / 100 }, { scaleX: progressRatio / 100 })

    preValue = progressRatio   // 把最新进度值赋给外边变量
    if (progressRatio === 100) {
      // loader 加载器工作完毕 → 向外传出模型数组 + 隐藏加载标签
      suc(model)
      document.querySelector('.loading').style.display = 'none'
    }
  }
  // 保存加载成功模型对象数组
  const model = []
  pathList.forEach(path => {
    if (path.indexOf('fbx') > -1) {
      fbxLoader.load(path, obj => { model.push({ model: obj, url: path }) })
    } else if (path.indexOf('gltf') > -1) {
      gltfLoader.load(path, obj => { model.push({ model: obj.scene, url: path }) })
    }
  })
}
```

**GSAP 知识点：** `to` 从目标当前值补间到指定值；`fromTo` 明确指定起点和终点；`onUpdate` 生命周期在动画过程多次触发；`this.targets()[0]` 拿正在做动画的目标标签；GSAP 只能对**数字**做补间，% 后缀在 onUpdate 里拼。

## 24 项目-产业分布查看（2D 饼图 → 3D 高亮联动）

**要点：** 点击饼图某一产业 → 对应模型区域高亮蓝色；再点其他产业 → 上一个恢复原材质（**排他思想**，但不用遍历排他，而是用实例属性单独记录上一个）。

**charts 侧（饼图点击，按 dataIndex 映射模型名）：**
```js
// mock 产业数据只有 5 种，上海_07 暂未用上（模型与数据要和后端对齐）
if (param.dataIndex == 0) {
  EventBus.getInstance().emit('pieClick', 'Shanghai-02')
} else if (param.dataIndex == 1) {
  EventBus.getInstance().emit('pieClick', 'Shanghai-03')
} // ... Shanghai-04 / Shanghai-05 / Shanghai-06
```

**入口（entry/index.js）：**
```js
import { modifySelectCityMaterial } from '@/shader/modifyCityMaterial'

// 监听自定义饼状图事件，让模型高亮
city.lastOriginMat = []   // 上一次高亮物体本来的材质
EventBus.getInstance().on('pieClick', buildName => {
  // 如果有上一个物体，先把上一个物体的材质恢复一下
  let index = 0
  if (city.lastClick && city.lastOriginMat.length > 0) {
    city.lastClick.traverse(obj => {
      obj.material = city.lastOriginMat[index]   // 按顺序从保存的数组里恢复
      index++
    })
  }
  const targetBuild = city.model.getObjectByName(buildName)
  targetBuild.traverse(model => {
    if (model.type === 'Mesh') {
      city.lastOriginMat.push(model.material)   // 保留小物体中每个细节物体的材质对象
      model.material = new THREE.MeshBasicMaterial({ color: 0x0000ff })  // 高亮蓝
    }
    modifySelectCityMaterial(model)   // 再给选中的小物体边线设置上去（着色器改写）
  })
  city.lastClick = targetBuild   // 记录本次点击的物体，供下次恢复
})
```

**代码解释：** 每个"小物体"内部还有更细节的子 Mesh，所以 traverse 逐个保存/替换材质；`modifySelectCityMaterial` 是 shader/modifyCityMaterial.js 里另一个导出函数，负责高亮后把黑色边线重新描上。

## 26 项目-three.js 项目移植到 Vue 中

**核心认知：** three.js 是**面向对象 + 面向过程**开发，几乎没有标签与数据的双向绑定 → 移植到 Vue 时，**原 JS 代码直接放进 .vue 文件的 script 部分**即可，不需要响应式改造。

**移植步骤：**
1. 创建 Vue2/Vue3 项目，下载 6 个依赖包：`three`、`echarts`、`gsap`、`axios`、`less`、`less-loader`
2. **标签**：原 HTML 标签放进 App.vue 模板（智慧城市只有一个页面）；可用 `v-for` 循环相同结构、`@click` 绑事件；左侧 2D 菜单和右侧按钮可拆成组件，用 Vuex/Pinia/EventBus 通信
3. **样式**：styles 放 src 下，`import` 引入页面样式
4. **资源**：模型/贴图等资源文件夹直接复制到 Vue 项目 `public/` 下
5. **JS 逻辑**：原来写的所有类文件（model/effect/dom/utils/shader）直接 Ctrl+C/V 复制；入口代码（3D 入口 + menu + charts 入口）放 App.vue 或 main.js
6. **eslint**：按提示逐一修复"定义了未使用"等风格问题
7. **⚠️ Vue 的 DOM 是异步渲染的**：menu.js 里获取真实标签（右上角按钮）必须包在 `nextTick` 回调里，等 DOM 挂载后才能拿到
8. 启动 Vue 项目时**别忘了同时启动 apifox** mock 服务

### 入口完整代码（entry/index.js 关键骨架）
```js
window.addEventListener('DOMContentLoaded', function () {
  init()          // 场景/相机/渲染器/CSS2DRenderer
  createLight()   // 灯光

  // 1. 天空背景
  const sky = new Sky(scene)
  sky.setBack('texture/sky/', ['px.jpg', 'nx.jpg', 'py.jpg', 'ny.jpg', 'pz.jpg', 'nz.jpg'])

  // 2. 注册光线投射
  ClickHandler.getInstance().init(camera)

  // 3. 加载模型（带进度条）
  loadManager(['fbx/city.fbx', 'gltf/ship.glb'], modelList => {
    modelList.forEach(async obj => {
      if (obj.url === 'fbx/city.fbx') {
        const city = new City(obj.model, scene, camera, control)

        // 接收默认数据和更新数据
        const data = await DataManager.getInstance().getData()
        city.dataObj = data

        // 监听自定义饼状图事件，让模型高亮
        city.lastOriginMat = []
        EventBus.getInstance().on('pieClick', buildName => {
          let index = 0
          if (city.lastClick && city.lastOriginMat.length > 0) {
            city.lastClick.traverse(obj => { obj.material = city.lastOriginMat[index]; index++ })
          }
          const targetBuild = city.model.getObjectByName(buildName)
          targetBuild.traverse(model => {
            if (model.type === 'Mesh') {
              city.lastOriginMat.push(model.material)
              model.material = new THREE.MeshBasicMaterial({ color: 0x0000ff })
            }
            modifySelectCityMaterial(model)
          })
          city.lastClick = targetBuild
        })

        // 监听自定义刷新数据事件，实现火灾标记切换
        EventBus.getInstance().on('refreshHomeCount', data => {
          const buildName = data.fireBuilding.name
          if (buildName) city.initFire(buildName)
        })
      } else if (obj.url === 'gltf/ship.glb') {
        const ship = new Ship(obj.model, scene, camera, control)
        ship.model.position.set(150, 0, -80)
        ship.model.rotation.set(0, -Math.PI / 2, 0)
        ship.model.scale.set(100, 100, 100)   // 游船很小，要放大匹配城市

        // 让游船物体也做动效
        EffectManager.getInstance().addObj(ship)
        // 订阅改变摄像机跟随游船移动的事件
        EventBus.getInstance().on('mode-roaming', isOpen => {
          ship.control.enabled = !isOpen   // 关闭/开启轨道控制器
          ship.isMoveCamera = isOpen
        })
      }
    })

    // 生成飞行器对象
    const meshObj = new THREE.Mesh(
      new THREE.BoxGeometry(5, 5, 5),
      new THREE.MeshBasicMaterial({ color: 'lightblue' })
    )
    meshObj.visible = false   // 只隐藏外观，坐标仍驱动鸟瞰
    const fly = new Fly(meshObj, scene, camera, control)
    EffectManager.getInstance().addObj(fly)
    // 注册事件-控制摄像机是否移动鸟瞰
    EventBus.getInstance().on('mode-topView', (isOpen) => {
      fly.control.enabled = !isOpen
      fly.isCameraMove = isOpen
    })

    // 启动 15 秒轮询（更新左上角数据 + 火灾切换）
    DataManager.getInstance().refreshData()
  })

  renderLoop()
})

// 渲染循环（所有动效的唯一驱动源）
function renderLoop(t) {
  // 这里不再调用轨道控制器 update 方法，会影响摄像机 lookAt
  renderer.render(scene, camera)
  css2Renderer.render(scene, camera)
  // 开始做动效->遍历所有要做动效的实例物体内置的 onTick 方法
  EffectManager.getInstance().tickForEach(t)
  requestAnimationFrame(renderLoop)
}
```

### 全项目踩坑与经验汇总
| 坑 | 解法 |
|---|---|
| 城市模型 100+ 单位被远截面裁掉 | 相机 far 设 10000 |
| renderLoop 里 controls.update() 锁定相机朝向 | 不要调 |
| traverse 隐藏 text 标签后没 return，又走进 else 加边线 | 隐藏后立刻 return |
| copy() 接收 Vector3、set() 接收三个数 | 别混用 |
| GLTF 要取 .scene | gltfLoader 回调里 model.scene |
| CSS2D 标签默认 pointer-events:none 点不了 | 子元素单独设 `pointerEvents = 'all'` |
| bind(this) 创建的函数 removeEventListener 移除不掉 | 改用类字段箭头函数 `fn = () => {}` |
| 手动 rotateY 与 lookAt 互相覆盖 | 鼠标按下时跳过 lookAt（isMouseTouching） |
| FireBall 创建瞬间闪一下完整半球 | 创建时先 scale.set(0,0,0) |
| 销毁 three 物体要释放显存 | geometry.dispose() + material.dispose() + scene.remove() |
| Vue 中 DOM 异步渲染拿不到标签 | nextTick 里再获取 |
| GSAP 只能补间数字 | % 后缀在 onUpdate 里拼；scaleX 用进度/100 |

### 动效实现套路（onTick 三范式）
1. **改材质 uniform**：`material.uniforms['time'].value = t / 1000`（水波纹）
2. **改坐标（路径数组 + 索引累加）**：`position.copy(arr[i])` + `lookAt(arr[i+1])`（游船/飞行器）
3. **改缩放/旋转等属性**：`scale.set(s, s, s)`（火灾半球扩散）

> 统一入口：EffectManager 单例 + renderLoop 的 requestAnimationFrame 毫秒值 t；要做动效的类**必须实现 onTick 方法**（接口约定）。
