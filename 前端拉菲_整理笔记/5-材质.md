# 5 - 材质（Materials）

> 本目录 16 集视频（01~15，其中 04 分上下两集）：系统学习 three.js 的**材质体系**——
> 基础网格材质的 3 种贴图（颜色/透明度/环境遮挡）→ 受光照影响的 Lambert/Phong → 基于物理渲染（PBR）的 Standard/Physical → 环境贴图 → 模型文件加载与调试 → 相机位置与观察点 → 世界/模型坐标系。

## 01 基础网格材质_颜色贴图

### 本集要点

1. 颜色贴图 ≠ color 纯色：`map` 属性贴一张图片当"皮肤"。
2. 固定套路：**创建几何图形 → 纹理加载器加载图片 → 材质装入纹理 → 网格物体入场景**。
3. 贴图发浅：设置 `texture.colorSpace = THREE.SRGBColorSpace`。
4. 素材：`public/texture/one/` 下有 basecolor.jpg、opacity.jpg、ambientOcclusion.jpg、roughness.jpg、metalness.jpg、displace_height.jpg、normal.jpg、target.jpg。

### 代码（main.js）

```js
// 目标：基础网格材质-颜色贴图
// 步骤：
// 1. 创建几何图形
// 2. 定义纹理对象（图片）
// 3. 创建网格材质，装入纹理
// 4. 生成物体加入到场景中
function initBase() {
  // 1. 创建几何图形
  const geometry = new THREE.SphereGeometry(1, 32, 16)  // 半径, 水平分割, 垂直分割

  // 2. 定义纹理对象（图片）
  const textureLoader = new THREE.TextureLoader()
  const texture = textureLoader.load('texture/one/basecolor.jpg')  // public 是服务器根目录
  texture.colorSpace = THREE.SRGBColorSpace  // 颜色通道：贴近原图，不发浅

  // 3. 创建网格材质，装入纹理
  const material = new THREE.MeshBasicMaterial({
    map: texture // 颜色贴图
  })

  // 4. 生成物体加入到场景中
  const mesh = new THREE.Mesh(geometry, material)
  scene.add(mesh)
}
initBase()
```

> 补充：任何宽高比的图片都能包裹到球体上；6 张全景图那种贴法只是为了好区分，包裹球体要用特殊构造函数（CubeTextureLoader，见第 10 集）。

## 02 基础网格材质_透明度贴图

### 本集要点

1. 透明度贴图 = **黑白灰度图**：黑色（RGB 0,0,0）→ 完全透明；白色 → 完全不透明；灰色 → 半透明。
2. 用 `alphaMap` 属性承载；**必须同时 `transparent: true`** 开启材质透明。
3. 与 `opacity` 的区别：`opacity` 控制**整体**透明度，`alphaMap` 控制**局部**（按图片逐像素）。

### 代码（在 01 基础上追加）

```js
// 1. 创建透明度贴图纹理对象
const alphaTexture = textureLoader.load('texture/one/opacity.jpg')
alphaTexture.colorSpace = THREE.SRGBColorSpace

const material = new THREE.MeshBasicMaterial({
  map: texture,
  alphaMap: alphaTexture, // 2. 传入透明度纹理对象（缝隙处透明，能透过球体看到坐标轴）
  transparent: true       // 开启透明（材质默认不透明）
  // opacity: 0.1         // 扩展：整体透明，与 alphaMap 部分透明的区别
})
```

## 03 基础网格材质_环境遮挡贴图

### 本集要点

1. 环境遮挡贴图（AO）：**模拟**光线遮挡的明暗对比，让物体更真实（实际没有光参与计算）。白 → 不遮光更亮；黑 → 遮光更暗。
2. 用 `aoMap` 属性承载。演示时要先把 alphaMap 注掉（透明区域会透过去看不到明暗）。
3. **扩展：第二组 UV**。`aoMap` 需要第二组 UV 坐标（uv2）；两张贴图同尺寸时可直接复用第一组：

```js
// 1. 环境遮挡贴图
const aoTexture = textureLoader.load('texture/one/ambientOcclusion.jpg')
aoTexture.colorSpace = THREE.SRGBColorSpace

const material = new THREE.MeshBasicMaterial({
  map: texture,
  // alphaMap: alphaTexture,
  // transparent: true,
  // opacity: 0.1,
  aoMap: aoTexture // 2. 设置环境遮挡贴图纹理对象
})

const mesh = new THREE.Mesh(geometry, material)
console.log(mesh)
// 扩展：给目标物体设置第二组 UV 坐标（影响贴图像素点转换对应映射过程）
// 当 aoMap 直接设置无效果时使用
mesh.geometry.setAttribute('uv2', new THREE.BufferAttribute(mesh.geometry.attributes.uv.array, 2))
scene.add(mesh)
```

> - `BufferAttribute(数组, 2)`：第二个参数表示**每 2 个数为一组**（UV 坐标是 u,v 成对）。
> - 查看物体属性路径：`mesh.geometry.attributes.uv.array`（Float32Array）。
> - 工作建议：实际项目中这些贴图由**建模师整合进模型文件**直接交付，了解原理即可。

## 04 Lambert 网格材质_基础（上）

### 本集要点

1. **为什么换材质**：MeshBasicMaterial 不受光照影响（纯颜色），不真实；Lambert 受光照影响。
2. Lambert = **非光泽表面、漫反射**（光打到像素点向四周发散），没有镜面高光。
3. 换材质后**必须有光**，否则全黑（世界里没光 = 全黑）。
4. 平行光 DirectionalLight：沿特定方向发射的平行光线，默认照向原点。
5. DirectionalLightHelper 可视化光源。

### 代码

```js
// 目标：Lambert 网格材质
// 作用：一种非光泽表面的材质（漫反射），没有镜面高光（受光照影响）
// 使用：
// 1. 替换网格材质的构造函数为 MeshLambertMaterial
// 2. 设置平行光 DirectionalLight 照亮物体
// 注意：ao 环境遮挡贴图只对"环境光"做计算（下集详解）

function initBase() {
  const geometry = new THREE.SphereGeometry(1, 32, 16)
  const textureLoader = new THREE.TextureLoader()
  const texture = textureLoader.load('texture/one/basecolor.jpg')
  texture.colorSpace = THREE.SRGBColorSpace

  // 只换构造函数，贴图属性照旧
  const material = new THREE.MeshLambertMaterial({
    map: texture,
    aoMap: aoTexture
  })
  const mesh = new THREE.Mesh(geometry, material)
  scene.add(mesh)
}

function createLight() {
  const direction = new THREE.DirectionalLight(0xffffff, 2)  // 参数1: 灯光颜色, 参数2: 强度
  direction.position.set(3, 3, 3)
  scene.add(direction)

  // 平行光辅助对象
  // 参数1：平行光对象，参数2：模拟平行光光源的大小
  const helper = new THREE.DirectionalLightHelper(direction, 5)
  scene.add(helper)
}

initBase()
createLight()
```

## 04 Lambert 网格材质中 ao 贴图对环境光的反应（下）

### 本集要点

1. 问题：换 Lambert 后 aoMap 明暗效果"失效"。
2. 原因：**aoMap 只对环境光（AmbientLight）做明暗计算**，对平行光无效。
3. 环境光：无方向、照亮场景中所有受光照影响的物体、不能投影。

### 代码（createLight 内追加）

```js
// 环境光（参数2 默认 1，写不写都行）
const ambient = new THREE.AmbientLight(0xffffff, 1)
scene.add(ambient)
```

> 加上环境光后：球体背面不再漆黑，AO 贴图的两条线重新出现明暗效果；正面 = 环境光 + 平行光叠加，更亮。

## 05 Phong 网格材质

### 本集要点

1. Phong = **具有镜面高光**的光泽表面材质（光直接反射进眼睛，形成光斑）。
2. 与 Lambert 最大区别：Lambert 漫反射无高光；Phong 有高光。
3. 注意：Phong 只是"模拟"光泽表面，更高级的是 Standard/Physical（性能与效果更好）。
4. `shininess` 控制高光亮度，值越高越亮。

### 代码

```js
const material = new THREE.MeshPhongMaterial({
  map: texture,
  aoMap: aoTexture,
  shininess: 100 // 光照的亮度（高光程度）
})
```

## 06 标准网格材质-粗糙度和贴图

### 本集要点

1. **MeshStandardMaterial = 基于物理渲染（PBR）**，不用近似值求光与表面作用，更真实但更费性能。
2. 独有属性 `roughness`（粗糙度，0~1）：0 = 光滑（镜面反光点）、1 = 粗糙（漫反射无反光点）、0.5 = 半反光半粗糙。
3. 局部控制：`roughnessMap` 粗糙度贴图（黑=光滑反光、白/灰=粗糙）。**与 roughness 同时设置时 roughness 建议写 1**（否则全光滑体现不出贴图作用）。
4. 文档提示：Standard 材质最好指定环境贴图（第 10 集兑现）。

### 代码

```js
// 粗糙度贴图
const roughTexture = textureLoader.load('texture/one/roughness.jpg')
roughTexture.colorSpace = THREE.SRGBColorSpace

const material = new THREE.MeshStandardMaterial({
  map: texture,
  aoMap: aoTexture,
  roughness: 1,                // 粗糙度：0 光滑 / 1 粗糙
  roughnessMap: roughTexture   // 粗糙度贴图（局部：缝隙反光、地板粗糙）
})
```

## 07 标准网格材质-金属度和贴图

### 本集要点

1. `metalness`（金属度，0~1）：决定反光部分的**光泽程度**；0 最低、1 最高。
2. **粗糙度管"能否反光"，金属度管"反光的光泽度"**，两者配合使用。
3. 金属度为 1 时表面发黑——因为材质**放射光颜色 emissive 默认黑色**，作衬底让金属对比更明显；有环境贴图后就不黑了（见第 10 集）。
4. `metalnessMap` 局部金属度贴图：与 metalness 值**相乘**（白 ×1 = 最高光泽）。
5. 坑：注释掉 roughness 后默认就是 1（全粗糙不反光），看不到金属度对比——别忘了粗糙度贴图让缝隙局部光滑。

### 代码

```js
// 金属度贴图
const metalnessTexture = textureLoader.load('texture/one/metalness.jpg')
metalnessTexture.colorSpace = THREE.SRGBColorSpace

const material = new THREE.MeshStandardMaterial({
  map: texture,
  aoMap: aoTexture,
  roughness: 1,
  roughnessMap: roughTexture,
  metalness: 1,                      // 金属度：光泽程度 0~1
  metalnessMap: metalnessTexture     // 金属度贴图（局部对比，与 metalness 相乘）
})
```

## 08 标准网格材质-位移贴图

### 本集要点

1. 位移贴图（凹凸贴图）：让物体表面真正**凹凸**（不再都在一个平面上）。
2. 原理：读贴图像素，黑色原地不动，白色最大位移（往外凸）。
3. `displacementScale` 控制位移程度：0 无位移，1 最大。

### 代码

```js
// 位移贴图
const displacementTexture = textureLoader.load('texture/one/displace_height.jpg')
displacementTexture.colorSpace = THREE.SRGBColorSpace

const material = new THREE.MeshStandardMaterial({
  // ...前面的属性
  displacementMap: displacementTexture, // 位移贴图
  displacementScale: 0.2                // 位移的范围 0~1
})
```

## 09 标准网格材质-法线贴图

### 本集要点

1. 问题：位移贴图后有凹凸，但光斑还是一个圆，不真实。
2. **法线**：垂直于物体表面每个像素点的线；法线贴图（RGB 彩色图）通过改变每个像素点法线方向，**影响光照反射角度**，让凹凸处明暗有区分。
3. 法线贴图内部是与光做数学运算（计算机图形学内容，本课不展开）。

### 代码

```js
// 法线贴图
const normalTexture = textureLoader.load('texture/one/normal.jpg')
normalTexture.colorSpace = THREE.SRGBColorSpace

const material = new THREE.MeshStandardMaterial({
  // ...前面的属性（Standard 特有：roughness/roughnessMap/metalness/metalnessMap/displacementMap/displacementScale）
  normalMap: normalTexture // 法线贴图 影响光照
})
```

> 多个贴图会同时对每个像素点运算，最终得出每个像素点的位置和颜色。

## 10 环境贴图

### 本集要点

1. 环境贴图是**公有的**（Basic/Lambert/Phong/Standard/Physical 都能用 `envMap`）。
2. 6 张图（px nx py ny pz nz）不能用 TextureLoader，要用 **CubeTextureLoader**（立方体纹理加载器）。
3. 配合 `metalness: 1` + `roughness: 0` → 金属球效果（文档说 envMap 让金属度效果更好）。
4. `scene.background = 环境纹理` → 天空盒子（背景不随相机移动）。
5. 粗糙度默认是 1——不设 metalness/roughness 时 envMap 看上去就是白的。

### 代码

```js
// 目标：标准网格材质-环境贴图
// 作用：模拟物体对四周内容的反射效果
function initBase() {
  const geometry = new THREE.SphereGeometry(1, 32, 16)

  // 1. 使用 CubeTextureLoader（立方体纹理加载器）- 6 个面的图片，得到纹理对象
  const cubeTL = new THREE.CubeTextureLoader()
  const cubeTexture = cubeTL.setPath('image/sky/').load(['px.jpg', 'nx.jpg', 'py.jpg', 'ny.jpg', 'pz.jpg', 'nz.jpg'])

  const material = new THREE.MeshStandardMaterial({
    // 2. 设置给物体的 envMap 环境贴图属性
    envMap: cubeTexture,
    roughness: 0,
    metalness: 1
  })

  const mesh = new THREE.Mesh(geometry, material)
  scene.add(mesh)

  // 天空盒子：给场景添加背景（不随相机移动）
  scene.background = cubeTexture

  // 3. 借助 GUI 工具，修改物体材质的粗糙度和金属度观察效果
  const gui = new dat.GUI()
  gui.add(material, 'roughness', 0, 1, 0.1)
  gui.add(material, 'metalness', 0, 1, 0.1)
}
```

## 11 物理网格材质-清漆度

### 本集要点

1. **MeshPhysicalMaterial = Standard 的扩展**，更高级的物理渲染属性，更费性能。
2. 独有属性（前几种材质没有）：
   - `clearcoat`（清漆度，0~1）：表面加一层薄膜（类似车漆/纤维/打湿表面）。
   - `clearcoatRoughness`（清漆粗糙度，0~1）：膜的粗糙程度，0 透光。
   - `reflectivity`（反射率）：模拟非金属材质，**metalness=1 时无效**（了解即可）。
3. 坑：直接给 Standard 材质加 clearcoat 控制台报警告 "clearcoat is not a property of MeshStandardMaterial" → 换构造函数。
4. three.js 属性值基本都是 0~1：内部做乘法计算，0=不要、1=要、小数=程度。

### 代码

```js
const material = new THREE.MeshPhysicalMaterial({  // 构造函数换掉！
  envMap: cubeTexture,
  roughness: 0,
  metalness: 1,
  clearcoat: 1,          // 清漆度（一层薄膜），注意 c 小写
  clearcoatRoughness: 0  // 清漆膜的粗糙度
})

const gui = new dat.GUI()
gui.add(material, 'clearcoat', 0, 1, 0.1)
gui.add(material, 'clearcoatRoughness', 0, 1, 0.1)
```

## 12 认识模型文件并使用

### 本集要点

1. 模型文件由建模师在专业软件设计导出，常见格式：**GLTF / GLB / FBX**；最常用 GLB（压缩整合后的二进制文件，包含物体所有信息）和 FBX（后续项目用）。
2. **GLTFLoader** 加载 .gltf/.glb；`load()` 是**异步**的，第二个参数是加载完成回调。
3. 回调参数上 `.scene` 属性才是真正的模型对象。
4. 模型材质多受光照影响 → 要加环境光；车灯亮是因为建模师给了自发光颜色。
5. `model.traverse()` 遍历模型内每个小物体。

### 代码

```js
// 1. 引入加载 gltf/glb 模型文件的加载器
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'

// 模型：包含网格、材质、贴图等信息的集合物体
// 模型文件：分为 .gltf，.glb，.fbx 等等类型
// 使用：借助 three.js 提供的 GLTFLoader 加载 .gltf/.glb 模型文件，得到模型对象
function initBase() {
  // 2. 实例化加载器并加载模型文件：load() 异步
  new GLTFLoader().load('model/ferrari.glb', gltf => {
    // 3. 取出模型对象并添加到场景中
    const model = gltf.scene
    scene.add(model)

    // 遍历物体内部每个小物体的组成部分
    model.traverse(obj => {
      console.log(obj)   // 打印出很多 Mesh，车由很多小网格对象组成
    })
  })
}

function createLight() {
  const light = new THREE.AmbientLight(0xffffff, 1)
  scene.add(light)
}

initBase()
createLight()
```

## 13 模型-查找并修改细节

### 本集要点

1. **three.js 官网在线模型编辑器**（官网首页左下 editor）：import 模型文件，右侧层级面板查看所有物体/灯光；选中物体看 name、position、rotation、scale、visible、geometry、material。
2. **定位某个小物体的技巧**：
   - 点选物体后看右侧面板高亮项的名字；
   - 勾掉 `visible` 看哪部分消失；
   - 改 position/rotation/scale 数值观察。
3. 本车车身的名字是 `Object_3`（建模师起名不达意，要靠技巧找）。车窗是 Object_77。
4. 车身材质是 MeshPhysicalMaterial：蓝绿色、metalness 1、roughness ≈ 0、emissive 黑。
5. **重点：环境光不反光**！环境光只能照亮、无方向、不能投影；金属度高的高级材质必须加**平行光**（或其他光源）才能看到颜色和反光。
6. 在线调好 → 把名字和属性回填到代码里。

model.traverse(obj => {

    obj.material.color = new THREE.Color('red')
  }
})

// 同时把平行光加回来（环境光不反光，高级材质需要它）

## 15 世界坐标系和模型坐标系

### 本集要点（概念课，代码已预置）

1. **世界坐标系**：整个场景（scene）立体空间的中心原点。
2. **模型坐标系**：每个物体自身的坐标系（原点不一定在物体正中心，取决于建模师）。
3. **位移参考父级坐标系**；**旋转、缩放参考自身坐标系**。
   - 绿色立方体加进 scene → 位移参考世界坐标原点；
   - 红色小立方体加进绿色立方体里 → 位移参考绿色立方体的坐标系。
4. 实战意义：让车"跑起来"要分两步——网格整体位移 + 轮子自身旋转。原 ferrari.glb 的 4 个轮子（Object_73）被建模师放在同一个物体里、坐标原点还不在中心，无法单独原地转轮子；官方例子的法拉利模型轮子拆得细、原点在轮心，才能直接旋转。
5. 结论：做交互前要和建模师沟通模型拆分粒度与坐标原点。

## 章末整合：材质全家福速查表

### 材质对比

| 材质 | 构造函数 | 受光照 | 特点 | 独有/常用属性 |
|---|---|---|---|---|
| 基础网格材质 | `MeshBasicMaterial` | ❌ | 纯颜色/贴图，最快 | map、alphaMap、aoMap |
| Lambert | `MeshLambertMaterial` | ✅ | 漫反射、无高光 | 同 Basic + 受光 |
| Phong | `MeshPhongMaterial` | ✅ | 镜面高光（模拟） | shininess |
| 标准 | `MeshStandardMaterial` | ✅ | PBR 物理渲染 | roughness、roughnessMap、metalness、metalnessMap、displacementMap、displacementScale、normalMap |
| 物理 | `MeshPhysicalMaterial` | ✅ | Standard 扩展、最真最贵 | clearcoat、clearcoatRoughness、reflectivity |

### 贴图/属性速查

| 需求 | 属性 | 说明 |
|---|---|---|
| 颜色贴图 | `map` | 图片当皮肤 |
| 局部透明 | `alphaMap` + `transparent: true` | 黑透白不透 |
| 整体透明 | `opacity` | 0~1 |
| 明暗对比 | `aoMap` | 只对环境光计算；无效时补 `setAttribute('uv2', ...)` |
| 高光亮度 | `shininess` | Phong 专用 |
| 粗糙度 | `roughness` 0~1 / `roughnessMap` | 0 光滑 1 粗糙；同设时 roughness 写 1 |
| 金属度 | `metalness` 0~1 / `metalnessMap` | 反光光泽；与贴图相乘；配 envMap 效果最好 |
| 凹凸 | `displacementMap` + `displacementScale` | 黑色不动白色凸 |
| 光照反射角度 | `normalMap` | RGB 法线贴图 |
| 环境反射 | `envMap`（CubeTextureLoader 6 张图） | 公有属性；`scene.background` 做天空盒 |
| 表面薄膜 | `clearcoat` + `clearcoatRoughness` | Physical 专用 |
| 放射光 | `emissive`（默认黑色） | 不受光照影响的固有颜色 |

### 常见坑速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 贴图颜色发浅 | 颜色通道不对 | `texture.colorSpace = THREE.SRGBColorSpace` |
| alphaMap 没效果 | 材质默认不透明 | 加 `transparent: true` |
| aoMap 没效果 | 只对环境光计算 | 加 `AmbientLight`；或补第二组 UV `uv2` |
| 换 Lambert/Standard 后全黑 | 没有光源 | 加平行光/环境光 |
| 金属度 1 时全黑 | emissive 默认黑色衬底 | 加环境贴图 envMap |
| clearcoat 报警告 | 它不是 Standard 的属性 | 换 `MeshPhysicalMaterial` |
| lookAt 不生效 | OrbitControls 覆盖了它 | 改 `controls.target` |
| 轮子不能原地转 | 模型坐标原点不在轮心/轮子没拆分 | 找建模师调整模型 |
| 环境光下金属材质发暗 | 环境光不反光 | 加平行光 |
