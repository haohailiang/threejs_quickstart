# 6 - 光源（Lights）

> 本目录 5 集视频（16~20）：系统学习三种常用光源（环境光/点光源/平行光/聚光灯）+ 灯光阴影。
> 承接《5-材质》：光只对**受光照影响的材质**（Lambert/Phong/Standard/Physical）起作用，对 MeshBasicMaterial 无效。
> 演示工程：Vite（03-code），地面 = 10×10 平面 + MeshStandardMaterial。

---

## 16 光源-环境光

### 本集要点

1. 环境光（AmbientLight）：**无方向、均匀照亮所有受光照影响的物体**，适合作为基础光源。
2. 两个注意事项：
   - 环境光**不能产生阴影**（没方向），也**不能产生光斑**（不反光）；
   - 如果材质 roughness=0、metalness=1、没有环境贴图、emissive 默认黑 → 加环境光也是黑的（不是光没生效，是金属反光衬底为黑）。
3. 目标效果：10 单位平面当地面，被环境光照亮。
4. 平面默认朝向相机（竖着），要**绕 X 轴转 -π/2** 放平（+π/2 会背朝上不可见，除非双面渲染）。

### 代码（main.js）

```js
function createFloor() {
  // 1. 创建平面缓冲几何体
  const geometry = new THREE.PlaneGeometry(10, 10)
  const material = new THREE.MeshStandardMaterial({
    color: 0xffffff
  })
  const plane = new THREE.Mesh(geometry, material)
  plane.rotation.set(- Math.PI / 2, 0, 0)  // 绕 X 轴 -90° 放平（-π/2，也可写 -0.5 * Math.PI）
  scene.add(plane)
}

function createLight() {
  // 2. 创建环境光
  const light = new THREE.AmbientLight(0xffffff, 1)  // 参数1 颜色, 参数2 强度（默认 1）
  scene.add(light)
}

createFloor()
createLight()

// 覆盖 init.js 中的相机初始位置，便于观察
camera.position.set(5, 5, 5)
```

> 材质选型逻辑：要受光 → 不能选 MeshBasicMaterial；要调粗糙度/金属度 → 选 MeshStandardMaterial。

## 17 光源-点光源

### 本集要点

1. 点光源（PointLight）：模拟**灯泡/路灯**——从一个点向各个方向发光，**离得越远越暗**（衰退）。
2. 构造参数：`(颜色, 强度=1, 照射最远距离=无限, 衰退量)`。
3. 配套辅助对象 PointLightHelper（可选）：虚拟球形标记光源位置。

### 代码（替换 createLight）

```js
// 点光源：模拟一个灯泡向四周发射光线
const light = new THREE.PointLight(0xffffff, 1)  // 可再加：参数3 照射最远距离, 参数4 衰退量
light.position.set(3, 3, 3)
scene.add(light)

// 点光源辅助对象（可选）：参数1 灯光对象，参数2 模拟球大小
const helper = new THREE.PointLightHelper(light, 1)
scene.add(helper)
```

> 点光源向四周都发光，但照不到没有物体的地方（没物体反射就看不见）。

## 18 光源-平行光

### 本集要点

1. 平行光（DirectionalLight）：沿**特定方向**发射平行光线，模拟太阳光（太阳离我们极远，光线到达时近似平行）。
2. **与环境光的最大区别**：
   - 平行光只照亮**面向光源的表面**，背面是暗的；环境光所有面都亮；
   - 平行光能让金属/光滑材质**反光产生光斑**，环境光不能。
   - 实际项目两个一起用：环境光打底，平行光出效果（正面更亮）。
3. **灯光不能旋转**，改变照射方向要设置 `light.target`（默认照向世界坐标原点 0,0,0）。
4. 一个场景可以放多个光源，从四面八方照射。

### 代码（替换 createLight）

```js
// 平行光（模拟太阳的光线）
const directionalLight = new THREE.DirectionalLight(0xffffff, 1)
directionalLight.position.set(3, 3, 3)   // 从 (3,3,3) 照向默认 target(0,0,0)
scene.add(directionalLight)

// 平行光辅助对象：参数1 平行光对象，参数2 模拟光源的大小
const helper = new THREE.DirectionalLightHelper(directionalLight, 1)
scene.add(helper)
```

> 辅助对象里那个"小方框"只是模拟光源位置和方向的标记，不代表光照范围——平行光是沿该方向照亮所有面的。

## 19 光源-聚光灯

### 本集要点

1. 聚光灯（SpotLight）：从一个点沿一个方向射出，**距离越远光锥越大**——模拟手电筒/舞台聚光灯。
2. 构造参数：`(颜色, 强度, 距离, 光锥角度)`——第 4 个参数控制圆锥张开角度。
3. **`spotLight.map` = 灯光纹理**：把图片 RGB 与灯光颜色混合后打在目标物体上（相当于投影仪效果；图片发浅记得设 `texture.colorSpace`）。
4. 辅助对象 SpotLightHelper 可观察光源位置和照射锥。

### 代码

```js
// 聚光灯（手电）
const spotLight = new THREE.SpotLight(0xffffff, 1)
spotLight.position.set(3, 3, 3)

// 灯光的纹理：会把图片和聚光灯的颜色混合后打在目标物体上（不太常用，了解即可）
spotLight.map = new THREE.TextureLoader().load('image/desert.jpg')

scene.add(spotLight)

// 聚光灯辅助对象
const spotLightHelper = new THREE.SpotLightHelper(spotLight)
scene.add(spotLightHelper)
```

> 设置光锥角度：`new THREE.SpotLight(0xffffff, 1, 1, Math.PI / 3)`（第 3 个距离参数占位后再写第 4 个角度）。

## 20 灯光与阴影

### 本集要点

1. **阴影三要素**：有方向的灯光 + 遮挡光的物体 + 接收阴影的平面。
2. 环境光没有方向 → **不能产生阴影**（能产阴影的是点光源/平行光/聚光灯）。
3. **产生阴影的 4 步**（缺一不可）：
   ① 渲染器开启阴影支持 → ② 灯光 castShadow → ③ 物体 castShadow → ④ 平面 receiveShadow。
4. 接收阴影的平面**不能用 MeshBasicMaterial**（它不受光照影响）。
5. 阴影非常耗性能（要计算灯光、物体、平面所有相关像素）。
6. 聚光灯阴影马赛克：阴影贴图太小 → 调大 `light.shadow.mapSize`（值必须是 **2 的幂**：512/1024/2048/4096...）。
7. 扩展：`light.shadow.camera` 是从"光的世界"看出去的透视相机（生成阴影深度图），有近截面/远截面/角度，默认值通常够用。

### 代码（main.js 完整核心）

```js
import { camera, scene, renderer } from './utils/init.js'

// 灯光（聚光灯示例）
function createLight() {
  const spotLight = new THREE.SpotLight(0xffffff, 1)
  spotLight.position.set(13, 13, 13)     // 灯离远一些，阴影大小合适

  spotLight.castShadow = true            // ② 灯光产生阴影

  // 让聚光灯打出阴影贴图大小（2 的几次幂值）——解决阴影马赛克
  spotLight.shadow.mapSize.width = 2048
  spotLight.shadow.mapSize.height = 2048

  scene.add(spotLight)

  const spotLightHelper = new THREE.SpotLightHelper(spotLight)
  scene.add(spotLightHelper)
}

// 物体（挡光产生阴影）
function createSphere() {
  const geometry = new THREE.SphereGeometry(1, 32, 16)
  const material = new THREE.MeshStandardMaterial({ color: 0x00ff00 })  // 绿色
  const mesh = new THREE.Mesh(geometry, material)
  mesh.position.set(0, 1, 0)           // 半径 1，上移 1 个单位刚好落在地面上
  mesh.castShadow = true               // ③ 物体产生阴影（参与阴影计算）
  scene.add(mesh)
}

// 平面（接收阴影）
function createFloor() {
  const geometry = new THREE.PlaneGeometry(10, 10)
  const material = new THREE.MeshStandardMaterial({ color: 0xffffff })  // 不能用基础材质！
  const plane = new THREE.Mesh(geometry, material)
  plane.rotation.set(- Math.PI / 2, 0, 0)
  plane.receiveShadow = true           // ④ 平面接收阴影
  scene.add(plane)
}

// ① 渲染器开启阴影支持（阴影很耗性能，默认关闭）
renderer.shadowMap.enabled = true

camera.position.set(5, 5, 5)
createLight()
createSphere()
createFloor()
```

## 章末整合：四种光源速查表

| 光源 | 构造函数 | 方向 | 阴影 | 光斑（反光） | 典型用途 | 辅助对象 |
|---|---|---|---|---|---|---|
| 环境光 | `AmbientLight(color, intensity)` | 无方向 | ❌ | ❌ | 基础打底，均匀照亮 | 无 |
| 点光源 | `PointLight(color, intensity, distance, decay)` | 向四周 | ✅ | ✅ | 灯泡、路灯 | PointLightHelper |
| 平行光 | `DirectionalLight(color, intensity)` | 特定方向 | ✅ | ✅ | 太阳光 | DirectionalLightHelper |
| 聚光灯 | `SpotLight(color, intensity, distance, angle)` | 锥形 | ✅ | ✅ | 手电筒、舞台灯 | SpotLightHelper |

### 常用结论

- **灯光也是物体**：要 `scene.add()` 才生效；可以改 `position`；**不能旋转**，改方向用 `light.target`。
- 环境光 + 平行光是常见组合：一个管"都看得见"，一个管"有明暗有反光"。
- 阴影四步口诀：**渲染器开 shadowMap → 灯 castShadow → 物 castShadow → 地 receiveShadow**。
- 阴影贴图 mapSize 必须是 **2 的幂**。
- 接收阴影的面不能用 MeshBasicMaterial。
