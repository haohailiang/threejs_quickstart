# 案例-法线贴图

> normalMap：改每个像素的法线方向 → 光照反射角度各不相同

## 效果
左右两个金属球对比：**左边无法线贴图**（光滑，一个大高光），
**右边有法线贴图**（高光被打碎成水波纹状的细密反射）。
光源可自动绕场景旋转，观察两球高光的变化差异。

## 知识点
- 法线贴图（蓝紫色图）RGB 通道存的是每像素法线的 XYZ 偏移。
- `normalScale`（Vector2）：法线强度，拖到 0 两球变得一样。
- **与位移贴图的区别**：法线贴图只改光照不改几何，轮廓仍是光滑球。
- 法线贴图是数据图，**不能设 sRGB**（设了法线数据被提亮，光照全错）。
- 法线贴图要用配套的 UV；`texture.repeat` 平铺可控制纹理密度。
