# 案例-物理台球滚动（边跳边滚 + 摩擦）

模拟台球：母球带**上抛分量 + 自旋**击出，落地弹跳几次后进入纯滚动，撞库反弹、撞散彩球，最终因阻尼停下。

## 三个力各管一件事

| 参数 | 作用 |
| --- | --- |
| 上抛初速度 `vy > 0` | 球离地 → "边跳" |
| 自旋 `angularVelocity.z` | 落地时球在滑动，摩擦力把它磨成滚动 |
| `linearDamping / angularDamping` | 能量耗散 → 最终停下 |

## 纯滚动的判断（HUD 实时显示）

```
接触点滑移速度 slip = v_x + ω_z · R     （沿 X 运动时）
slip ≈ 0 → 纯滚动；slip 很大 → 打滑
```

ωz 为负 = 向前滚（右手定则，ω × 接触点半径 抵消速度）。

## 场景构成

- 台呢 = Plane（摩擦 0.4 / 弹性 0.42）
- 四个库边 = 静态 Box（弹性 0.85，撞库有力）
- 6 颗球 = Sphere（质量 0.17kg，球-球弹性 0.92）
- `world.step(1/180, dt, 6)`：台球速度快、接触频繁，步长要更细防穿模
